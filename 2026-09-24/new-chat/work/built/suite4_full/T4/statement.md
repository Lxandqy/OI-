# 表达式（eval）

**输入文件：** `eval.in`  
**输出文件：** `eval.out`  
**时间限制：** $1\text{ s}$  
**空间限制：** $512\text{ MiB}$

## 题目描述

给定一个只由正整数、加号 `+` 和乘号 `*` 组成的合法表达式 $S$。

你可以在表达式中的任意合法位置添加任意多对括号，但不能改变数字和运算符的原有顺序。求能够得到的最大表达式值。

## 输入格式

一行一个字符串 $S$。

## 输出格式

输出一行一个正整数，表示最大值。答案可能非常大，需要输出完整十进制表示。

## 样例 1

```text
1*2+2*1
```

```text
4
```

## 样例 2

```text
1*2345+6789*9867+5432*1
```

```text
139741066
```

## 样例说明

样例 1 可以变为 $1\times(2+2)\times1=4$。

样例 2 可以变为

$$(1\times2345+6789)\times(9867+5432\times1)
=1\times(2345+6789)\times(9867+5432)\times1。$$


## 数据范围与子任务

设 $|S|$ 为字符串长度，$n$ 为正整数个数，第 $i$ 个数为 $a_i$。

- $1\le|S|\le5\times10^3$；
- $1\le n\le\lceil |S|/2\rceil$；
- $1\le a_i<10^{|S|}$。

本题共 $20$ 个测试点，每点 $5$ 分。

| 测试点 | $|S|\le$ | $a_i$ | 特殊性质 |
|---:|---:|---:|---|
| $1\sim2$ | $10$ | $<10^9$ | 无 |
| $3\sim4$ | $5000$ | $\le1$ | 无 |
| $5\sim6$ | $5000$ | $\le9$ | 无 |
| $7\sim8$ | $5000$ | $<10^9$ | 只有 `+` |
| $9\sim10$ | $5000$ | $<10^{|S|}$ | 只有 `+` |
| $11\sim12$ | $5000$ | $<10^{|S|}$ | 只有 `*` |
| $13\sim14$ | $1000$ | $<10^{|S|}$ | 无 |
| $15\sim20$ | $5000$ | $<10^{|S|}$ | 无 |
