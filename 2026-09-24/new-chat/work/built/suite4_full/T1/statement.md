# 接龙

**时间限制：** $1\text{ s}$  
**空间限制：** $256\text{ MB}$

## 题目描述

牛牛有 $n$ 张牌，第 $i$ 张牌上的数字为 $a_i$。他可以任意调整这些牌的放置顺序，然后依次把牌放到桌面一列的末尾。

每放置一张牌后，他可以进行至多一次收牌操作：从桌面上选择两张数字相同的牌，收走这两张牌以及它们之间的所有牌。若这两张相同的牌数字为 $x$，本次共收走 $len$ 张牌，则获得

$$x\times len$$

分。被收走的牌不会再次使用。牛牛也可以在某一回合不收牌。

求把所有牌都放置完以后，能够获得的最大总分。

## 输入格式

第一行输入一个正整数 $n$。

第二行输入 $n$ 个正整数 $a_1,a_2,\ldots,a_n$。

## 输出格式

输出一行一个整数，表示最大总分。

## 输入输出样例

### 样例 1

```text
4
3 3 4 4
```

```text
16
```

### 样例 2

```text
3
1 2 3
```

```text
0
```

### 样例 3

```text
3
5 5 5
```

```text
15
```

## 数据范围与子任务

- $1\le n\le10^5$；
- $1\le a_i\le10^5$。

本题共 $10$ 个测试点，每点 $10$ 分，下列前几类独立计分。

| 测试点 | 特殊限制 | 分值 |
|---:|---|---:|
| $1\sim2$ | $n\le100$ | $20$ 分 |
| $3\sim4$ | 所有牌数字相同 | $20$ 分 |
| $5\sim7$ | $a_i\le1000$ | $30$ 分 |
| $8\sim10$ | 无额外限制 | $30$ 分 |
