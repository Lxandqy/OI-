# 第二套 NOIP 模拟卷：教师说明

本轮重新设计四题的关键规则、满分推导和数据。题面与题解沿用原有 Markdown、PDF 格式。每题20点、每点5分，独立计分。

| 题目 | 规则变化及新核心 | 原题评级 | 改编后估计 |
|---|---|---:|---|
| 连续检修 | 同时选择两个起点；分析三段最晚时刻，以三状态最小化最大值 DP 选择起点。来源：[CF1901D](https://codeforces.com/problemset/problem/1901/D) | 1700 | 1600–1800 |
| 协同巡检 | 取消回根要求；证明全局最佳终点能够实现，在线性树形合并中求最大返程节省。来源：[CF1774E](https://codeforces.com/problemset/problem/1774/E) | 1900 | 2000–2100 |
| 三机编排 | 两台改为三台；两台空闲机器必须联合记录，维护对称矩阵、公共增量和列最值。来源：[CF1799D2](https://codeforces.com/problemset/problem/1799/D2) | 2100 | 2100–2300 |
| 区间合码 | 查询区间内所有子段代价之和；稀疏数对、单调等值块与历史贡献树状数组。来源：[CF1665E](https://codeforces.com/problemset/problem/1665/E) | 2500 | 2500–2600 |

来源评级于2026-10-18核对；改编后的数值是作者估计，未经学生盲测。T3 的联合状态与 [P4046 快递服务](https://www.luogu.com.cn/problem/P4046) 同构，冷热费用才使本题能够进一步按列最小值优化，不能称为全新状态模型。本卷明确作为改编训练使用。

四题分别侧重对抗顺序与状态、树上可达性、联合状态优化、位运算稀疏化与历史累计。按 [2025 NOI大纲](https://www.noi.cn/xw/2025-04-18/841584.shtml)核对，主解的数据结构以树遍历、DP、map和树状数组为主；T4还涉及大纲列入NOI级、系数8的批量离线思想。它定位在本卷上沿，适合作为挑战题。实际[NOIP 2025官方分析](https://www.noi.cn/xw/2026-09-20/933736.shtml)亦包含部分系数8的NOI级内容，但这不能代替本卷的学生试做。

公开题解仅给每题一份满分代码；部分分保留条件、保证分、关键做法和复杂度。独立std使用纯ASCII、无BOM，避免GBK编辑器显示乱码。

## 实测方法与结果

所有程序以 C++14、-O2、静态链接编译，单进程串行测时。Windows Job Object 限制内存，QPC墙钟包含进程启动；超时在期限强制结束，记录为“至少超过时限”，没有把终止时刻当成算法完整耗时。

部分输入调整后，改变的正式点和公开样例重新测量；源码、二进制、输入、答案、原生运行器、编译选项、时限和内存限制全部相同的点复用既有记录。复用保留原始运行时间及测量目录，不计作新增测量。

| 题目 | 时限 / 内存 | std最大耗时（全部一般点各5次） | 最大进程提交内存 |
|---|---|---:|---:|
| 连续检修 | 2秒 / 256 MiB | 0.086秒 | 6.3 MiB |
| 协同巡检 | 3秒 / 512 MiB | 0.159秒 | 15.6 MiB |
| 三机编排 | 3秒 / 256 MiB | 0.478秒 | 12.1 MiB |
| 区间合码 | 2秒 / 256 MiB | 0.154秒 | 28.5 MiB |

四份std、四份独立实现的全量核验程序均在20个正式点取得100分；所有阶段程序在承诺点均通过。全部一般压力点中，所测最高非满分算法的自然优化版本各复测5次，均超时；另在至少两个合法规模运行增长测试，其中超时测量只提供耗时下界，不能给出完整耗时或倍增比例。此结论针对下表实现及已覆盖优化，不是对所有可能慢算法的数学保证。

判定串按点1至20排列：A=AC，W=WA，T=TLE，M=MLE，R=RE。分数来自逐点实际运行；保证分与自然交叉性质带来的额外得分须区别看待。

T4 曾在6秒试测时发现立方程序能通过一个中档点，最终改为2秒并全部重测；正解一般点耗时见上表，31候选增量表算法在保证点的最大耗时为 0.316 秒。T2 的20万节点长链曾使递归候选栈溢出，最终代码用BFS顺序逆向合并。T4的64位中间系数有上界证明，并对5个高值正式点运行在标程运算前增加边界检查的探针，其输出与正式答案一致。该探针用于检查溢出，不作为独立答案算法。

输入均经范围与性质校验，正式答案由std与独立实现的全量核验程序交叉核对。T3的核验程序采用费用流，与矩阵DP不同；T4两份实现共用稀疏候选引理，分别使用删除链表/插入次序统计生成候选、历史树状数组/历史线段树累计，并另以不依赖该引理的小规模枚举对拍。32份公开输入与正式点、旧版公开输入进行了归一化隔离检查，树题另检查带双方任务标签的有根树同构。打包流程复核样例、公式、源码、PDF页面及归档内容，全部检查通过后才标记交付成功。原始日志、生成器、部分分与错解源码留内部，不放入本包。
