# 第四套 NOIP 模拟赛题解

---

# T1 升温统计（cut）

---

## 从一次删法开始

---

直接枚举删除区间，再扫描剩余数列：若当前项比前一项大，就把以当前位置结尾的上升段长度加一，否则重置为 $1$；把这些长度相加，就是升温段总数。总复杂度 $O(n^3)$，对应 $n\le300$ 的数据。

重复扫描的部分可以预处理。记 $L_i$ 为原数组以 $i$ 结尾的最长升温段长度，$R_i$ 为以 $i$ 开头的对应长度。于是

$$P_i=\sum_{u=1}^i L_u,\qquad Q_i=\sum_{u=i}^n R_u$$

分别是前缀和后缀内的升温段总数，令 $P_0=Q_{n+1}=0$。$L,R$ 各线性递推一次即可得到。

删除 $[l,r]$ 后，升温段有且只有三类：

- 完全位于保留的左侧，共 $P_{l-1}$ 个。
- 完全位于保留的右侧，共 $Q_{r+1}$ 个。
- 跨过接缝：要求 $l>1,r<n$ 且 $a_{l-1}<a_{r+1}$。左起点有 $L_{l-1}$ 种选择，右终点有 $R_{r+1}$ 种选择，两个选择独立，共 $L_{l-1}R_{r+1}$ 个。

每个升温段由起止点唯一确定，所以三类不重不漏。每种删法现在可以 $O(1)$ 求分，枚举所有 $l,r$ 为 $O(n^2)$，对应前 $10$ 个测试点。

## 把所有删法一起统计

---

前两类不用继续枚举区间。固定左端点 $l=i$，右端点有 $n-i+1$ 种；固定右端点 $r=i$，左端点有 $i$ 种。因此它们的总贡献为

$$\sum_{i=1}^n\bigl(P_{i-1}(n-i+1)+Q_{i+1}i\bigr).$$

虽然求和包含 $[1,n]$，但它的两项均为 $0$，不会改变答案。

对于跨缝部分，令 $i=l-1,j=r+1$，需要计算

$$\sum_{\substack{i\le j-2\\a_i<a_j}}L_iR_j.$$

固定右端 $j$，从左到右扫描。每次把位置 $j-2$ 加入候选，这样候选位置自动满足删除区间非空。剩下只需查询所有 $a_i<a_j$ 的 $L_i$ 之和，再乘 $R_j$。

当 $a_i\le100$ 时，用数组保存每个值对应的 $L_i$ 总和，查询时枚举较小的值，复杂度 $O(100n)$；与前面的规模档结合可保证前 $15$ 个测试点。

一般情况将数值离散化，用树状数组维护加权前缀和。加入排名 $p$ 时增加 $L_i$，查询 $a_j$ 排名减一的前缀，保证相等值不能拼接。总复杂度 $O(n\log n)$，空间复杂度 $O(n)$。

所有计数在计算中取模，乘法使用 `long long`。$n=1$ 时没有合法删法，前后缀贡献和跨缝贡献均为零；$n=2$ 时仅有前后缀贡献，无需额外特判。

## 部分分思路

---

下表分值是题面中各测试点组的分值，各组互不重叠；它不是该行算法能够取得的总分。

| 条件（测试点） | 点组分值 | 做法与复杂度 |
|---|---:|---|
| $n\le300$（1–5） | 20 分 | 枚举删除区间，扫描剩余数列，累加以各位置结尾的升温段数量。时间 $O(n^3)$。 |
| $n\le5000$（6–10） | 20 分 | 预处理正文中的 $L,R,P,Q$，每个删除区间的左右贡献和跨缝贡献均可在 $O(1)$ 内求出；枚举全部区间。时间 $O(n^2)$。 |
| $a_i\le100$（11–15） | 20 分 | 沿用贡献拆分，按右接缝位置扫描，用值域数组维护左侧各数值的 $L_i$ 之和；枚举小于当前值的数值，求跨缝贡献。时间 $O(100n)$。 |
| 无额外限制（16–25） | 40 分 | 将数值离散化，用树状数组维护上述加权前缀和，查询严格小于当前值的贡献。时间 $O(n\log n)$。 |

前两种做法分别保证前 20、40 分；按条件选择小规模做法或小值域做法，可以保证前 60 分。一般做法覆盖全部 100 分。删除区间必须非空且至少留下一项，跨缝拼接要求严格小于，不能把相等值计入。

## 参考代码

---

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 500010;
const int MOD = 998244353;
int n,m,a[N],b[N],L[N],R[N],t[N];
long long P[N],Q[N];
void add(int x,int v){
    for(; x <= m; x += x & -x){
        t[x] += v;
        if(t[x] >= MOD) t[x] -= MOD;
    }
}
int ask(int x){
    int sum = 0;
    for(; x > 0; x -= x & -x){
        sum += t[x];
        if(sum >= MOD) sum -= MOD;
    }
    return sum;
}
int main(){
    freopen("cut.in","r",stdin);
    freopen("cut.out","w",stdout);
    ios::sync_with_stdio(false);
    cin.tie(0);
    cin >> n;
    for(int i = 1; i <= n; i++){
        cin >> a[i];
        b[i] = a[i];
    }
    for(int i = 1; i <= n; i++){
        L[i] = 1;
        if(i > 1 && a[i - 1] < a[i]) L[i] = L[i - 1] + 1;
        P[i] = (P[i - 1] + L[i]) % MOD;
    }
    for(int i = n; i >= 1; i--){
        R[i] = 1;
        if(i < n && a[i] < a[i + 1]) R[i] = R[i + 1] + 1;
        Q[i] = (Q[i + 1] + R[i]) % MOD;
    }
    long long ans = 0;
    // 未跨接缝的上升段：按删除区间的左端点、右端点分别求和。
    for(int i = 1; i <= n; i++){
        ans = (ans + P[i - 1] * (n - i + 1) + Q[i + 1] * i) % MOD;
    }
    sort(b + 1,b + n + 1);
    m = unique(b + 1,b + n + 1) - b - 1;
    for(int i = 1; i <= n; i++){
        a[i] = lower_bound(b + 1,b + m + 1,a[i]) - b;
    }
    // 接缝为 i,j 时删去 i+1..j-1，跨缝上升段有 L[i]*R[j] 个。
    for(int j = 3; j <= n; j++){
        add(a[j - 2],L[j - 2]);
        ans = (ans + 1LL * ask(a[j] - 1) * R[j]) % MOD;
    }
    cout << ans << '\n';
    return 0;
}
```

# T2 最优区域（region）

---

对每个点，求包含它的连通点集的最大点权和，以及达到最大值的点集数量。

当 $n\le15$ 时，可以枚举全部非空点集，检查是否连通，再用它的点权和更新其中每个点的最优值和数量，复杂度 $O(n2^n)$，可得前 $12$ 分。

## 固定根后，各个分支怎样选择

---

先把树以 $1$ 为根。设 $f_u$ 为 $u$ 子树内、包含 $u$ 的连通块的最大权值，$g_u$ 为达到 $f_u$ 的连通块数量。

一个包含 $u$ 的连通块，与孩子 $v$ 的子树的交，要么为空，要么是包含 $v$ 的连通块；不同孩子之间的选择互不影响。因此：

- $f_v>0$：必须接上这个分支，并且只能选择达到 $f_v$ 的那 $g_v$ 个连通块。
- $f_v<0$：不接上这个分支。
- $f_v=0$：接上最优的 $g_v$ 个连通块或完全不接，收益一样，共有 $g_v+1$ 种选择。

记

$$
W(x,c)=\begin{cases}
c,&x>0,\\
1,&x<0,\\
c+1,&x=0.
\end{cases}
$$

则

$$
f_u=a_u+\sum_{v\text{ 是 }u\text{ 的孩子}}\max(0,f_v),\qquad
g_u=\prod_{v\text{ 是 }u\text{ 的孩子}}W(f_v,g_v).
$$

所有数量都对 $998244353$ 取模。没有孩子时，$f_u=a_u,g_u=1$；根本身必须被选，所以即使答案为负数，也不能改为空集。

对每个点重新选根并做一遍上述 DP，复杂度为 $O(n^2)$，覆盖前 $28$ 分。若树是链，各点只有左右两个方向，分别从左到右、从右到左递推，就能在 $O(n)$ 内求解；结合小规模做法可得前 $44$ 分。

## 把重复的子树计算留下来

---

相邻两个根重复计算了大量相同分支。对每条边，只需保存它两侧的最优值和数量。

仍以 $1$ 为根，$f_v,g_v$ 表示孩子 $v$ 这一侧；另设 $upf_u,upg_u$ 表示删去 $u$ 的子树后，父亲这一侧中必须包含父亲的连通块的最优值和数量。对于 $u$ 的每个邻居，取出对应方向的状态 $(h,c)$，就有

$$
M_u=a_u+\sum\max(0,h),\qquad C_u=\prod W(h,c).
$$

要把状态从 $u$ 传给孩子 $v$，只需排除 $v$ 这一侧：

$$
upf_v=M_u-\max(0,f_v),
$$

$upg_v$ 则是除去 $v$ 方向后，其余方向的方案因子之积。每个连通块都唯一对应各个方向的选择，反过来这些选择的并也一定连通，因此上述加法和乘法既不会漏算，也不会重复。

若每次排除一个方向时重新扫描其他邻居，时间为 $O(\sum_u\deg(u)^2)$。最大度为 $\Delta$ 时，这不超过 $O(n\Delta)$；结合小规模和链，可以覆盖前 $56$ 分。

进一步看，排除后的乘积只与被排除因子的值有关，相同因子可以共用一次计算。在特殊性质 A 中，每个点至多有两个非叶子邻居；叶子方向的因子只能是 $1$ 或 $2$，所以每个点至多出现四种因子。缓存这几种排除结果，每个点只需常数次扫描邻居，整题为 $O(n)$，可继续覆盖第 $15\sim17$ 点，累计 $68$ 分。

## 所有方向的排除乘积一次求完

---

一般树中，一个点可能有很多种方向因子。设它们按邻接表顺序为 $b_1,b_2,\ldots,b_k$，计算前缀积和后缀积。排除 $b_i$ 后的乘积就是

$$
\left(\prod_{j<i}b_j\right)\left(\prod_{j>i}b_j\right).
$$

空乘积取 $1$。不能直接用总乘积除以 $b_i$，因为因子可能在取模后等于 $0$。前后缀积直接避开了除法。

实现时先记录父亲在孩子之前的遍历顺序，逆序求出所有 $f,g$，再正序求出所有 $upf,upg$ 和答案。处理一个点时先算前缀积，再从后向前维护一个后缀积即可。每条边只被访问常数次，总时间、空间复杂度均为 $O(n)$。权值和的绝对值不超过 $2\times10^{14}$，使用 `long long`。

---

下表分值是题面中各测试点组的分值，各组互不重叠；它不是该行算法能够取得的总分。

| 条件（测试点） | 点组分值 | 做法与复杂度 |
|---|---:|---|
| $n\le15$（1–3） | 12 分 | 枚举全部非空点集，检查连通性，用点权和更新集合内各点的最大收益及方案数。时间 $O(n2^n)$。 |
| $n\le2000$（4–7） | 16 分 | 分别以每个点为根，执行正文的子树 DP，取得包含该根的最大收益和方案数。每次 $O(n)$，总时间 $O(n^2)$。 |
| 按编号顺序构成链（8–11） | 16 分 | 从左到右、从右到左分别递推方向状态，再合并每个点左右两侧的收益和方案因子。时间 $O(n)$。 |
| 最大度数 $\Delta\le32$（12–14） | 12 分 | 换根时，每排除一个方向就扫描其余邻居，求剩余方案因子之积。时间 $O(n+\sum_u\deg(u)^2)$，至多为 $O(n\Delta)$。 |
| 特殊性质 A（15–17） | 12 分 | 缓存相同因子的排除乘积。每点至多有两个非叶子邻居，叶子方向的因子只有 $1,2$，因而至多四种因子；每点只需常数次扫描邻居。时间 $O(n)$。 |
| 无额外限制（18–25） | 32 分 | 为邻居方向的方案因子构造前缀积、后缀积，一次求出全部排除乘积，再完成换根。时间 $O(n)$。 |

按规模和树形条件选用上述做法，累计保证分依次为 12、28、44、56、68、100 分。特殊性质 A 指同时删去原树所有叶子后剩下一条链；叶子自身的最优连通块只有一种，所以正权、负权叶子的方向因子都是 $1$，零权叶子的因子为 $2$。一般换根不能直接除以被排除的因子，因为它取模后可能为 $0$。

### 参考代码

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 2e5 + 10;
const long long MOD = 998244353;
int n,fa[N],ord[N];
vector<int> e[N];
long long a[N],f[N],g[N],upf[N],upg[N];
long long ansf[N],ansg[N],way[N],pre[N];
long long addWays(long long x,long long c){
	if(x > 0) return c;
	if(x < 0) return 1;
	return (c + 1) % MOD;
}
int main(){
	freopen("region.in","r",stdin);
	freopen("region.out","w",stdout);
	ios::sync_with_stdio(false);
	cin.tie(0);
	cin >> n;
	for(int i = 1; i <= n; i++) cin >> a[i];
	for(int i = 1; i < n; i++){
		int u,v;
		cin >> u >> v;
		e[u].push_back(v);
		e[v].push_back(u);
	}
	// ord 中父亲先于孩子；逆序可先求出全部子树状态。
	ord[1] = 1;
	int cnt = 1;
	for(int i = 1; i <= n; i++){
		int u = ord[i];
		for(int j = 0; j < (int)e[u].size(); j++){
			int v = e[u][j];
			if(v == fa[u]) continue;
			fa[v] = u;
			ord[++cnt] = v;
		}
	}
	// f[u],g[u]：u 子树内、包含 u 的连通块的最优值及方案数。
	for(int i = n; i >= 1; i--){
		int u = ord[i];
		f[u] = a[u];
		g[u] = 1;
		for(int j = 0; j < (int)e[u].size(); j++){
			int v = e[u][j];
			if(v == fa[u]) continue;
			f[u] += max(0LL,f[v]);
			g[u] = g[u] * addWays(f[v],g[v]) % MOD;
		}
	}
	// upf[u],upg[u]：父亲方向、必须包含 fa[u] 的最优值及方案数。
	for(int i = 1; i <= n; i++){
		int u = ord[i];
		int k = e[u].size();
		long long sum = a[u];
		pre[0] = 1;
		for(int j = 0; j < k; j++){
			int v = e[u][j];
			long long x,c;
			if(v == fa[u]){
				x = upf[u];
				c = upg[u];
			}else{
				x = f[v];
				c = g[v];
			}
			sum += max(0LL,x);
			way[j] = addWays(x,c);
			pre[j + 1] = pre[j] * way[j] % MOD;
		}
		ansf[u] = sum;
		ansg[u] = pre[k];
		long long suf = 1;
		for(int j = k - 1; j >= 0; j--){
			int v = e[u][j];
			if(v != fa[u]){
				upf[v] = sum - max(0LL,f[v]);
				upg[v] = pre[j] * suf % MOD;
			}
			suf = suf * way[j] % MOD;
		}
	}
	for(int i = 1; i <= n; i++){
		cout << ansf[i] << ' ' << ansg[i] << '\n';
	}
	return 0;
}
```

# T3 轨道（track）

---

先按初始位置排序，记 $y_i=x_i+Tv_i$。对于 $i<j$，两点的带符号间距是时间的一次函数：若 $y_i\ge y_j$，两点在区间内相遇；否则最近距离在某个端点取得。因此两点的最近距离为

$$d_{i,j}=\max\bigl(0,\min(x_j-x_i,y_j-y_i)\bigr).$$

三元组的值就是其三对机器人最近距离的最小值，答案为整数。

对于 $n\le100$，直接枚举三元组、计算值并排序，时间 $O(n^3\log n)$，空间 $O(n^3)$。只求第 $K$ 小时，可以使用线性期望复杂度的选择算法，把时间降为期望 $O(n^3)$，处理 $n\le800$。

## 二分答案与固定中点

---

对正整数 $D$，两点的最近距离不小于 $D$，当且仅当它们的初始位置差、终点位置差都至少为 $D$。

考虑按初始位置排序的三个点 $i<j<k$。三元组的值至少为 $D$，只需相邻的两对 $(i,j)$、$(j,k)$ 都满足上述条件：此时 $(i,k)$ 的两个位置差都是前两段之和，也一定满足条件。

固定中间的点 $j$，令

$$L_j=\#\{i<j:x_i\le x_j-D,\ y_i\le y_j-D\},$$

$$R_j=\#\{k>j:x_k\ge x_j+D,\ y_k\ge y_j+D\}.$$

左右各选一个点可以独立进行，所以三元组的数量为

$$C(D)=\sum_j L_jR_j.$$

设 $M=\binom n3$。第 $K$ 小值至少为 $D$，当且仅当 $C(D)\ge M-K+1$，因此可以二分最大的可行 $D$。答案不超过初始位置跨度 $X=x_n-x_1$；二分正数 $[1,X]$，答案初值为 $0$。

直接枚举点对计算全部 $L_j,R_j$，每次统计为 $O(n^2)$，总时间 $O(n^2\log X)$、空间 $O(n)$，可处理 $n\le2000$。另一个做法是将所有点对的距离降序排序，逐步加入有向边 $i\to j$：新边增加的长度为 2 的链有 $L_i+R_j$ 条；相同距离统一处理后判断数量是否足够。这样时间为 $O(n^2\log n)$、空间为 $O(n^2)$。

对于特殊性质 A，$x_i,y_i$ 都单调不减。每个 $L_j$ 对应一个前缀，$R_j$ 对应一个后缀，各用一次双指针即可在线性时间内统计。总时间 $O(n\log X)$。与小规模算法分派结合，可以保证通过前 15 个测试点。

## 一般数据

---

计算 $L_j$ 时，按 $j$ 从左到右扫描，用指针加入所有满足 $x_i\le x_j-D$ 的点，查询已加入点中 $y_i\le y_j-D$ 的个数。将 $y_i$ 离散化，用树状数组维护次数即可。

计算 $R_j$ 时反向扫描：加入满足 $x_k\ge x_j+D$ 的点，查询其中 $y_k\ge y_j+D$ 的个数。相同的终点位置只是共用离散下标，每个机器人仍单独计数。

每次统计为 $O(n\log n)$，总时间 $O(n\log n\log X)$，空间 $O(n)$。三元组数量、$K$、$L_jR_j$ 和它们的总和均使用 `long long`。

## 部分分思路

---

下表分值是题面中各测试点组的分值，各组互不重叠；它不是该行算法能够取得的总分。

| 条件（测试点） | 点组分值 | 做法与复杂度 |
|---|---:|---|
| $n\le100$（1–3） | 12 分 | 枚举三元组，用正文的两点最近距离公式求其值，排序后取第 $K$ 小。时间 $O(n^3\log n)$，空间 $O(n^3)$。 |
| $n\le800$（4–6） | 12 分 | 仍生成全部三元组值，用 `nth_element` 选出第 $K$ 小，省去完整排序。平均时间 $O(n^3)$，空间 $O(n^3)$。 |
| $n\le2000$（7–10） | 16 分 | 二分正阈值 $D$，枚举点对计算每个中点左右可选数量，再求 $\sum_j L_jR_j$。时间 $O(n^2\log X)$，空间 $O(n)$。 |
| 特殊性质 A（11–15） | 20 分 | 按初始位置排序后，终点位置也单调不减；各中点的左右可选集合分别是前缀、后缀，用双指针在线性时间内统计。总时间 $O(n\log n+n\log X)$，空间 $O(n)$。 |
| 无额外限制（16–25） | 40 分 | 二分正阈值，扫描初始位置，用树状数组统计终点位置满足要求的点数，求出各中点的贡献。时间 $O(n\log n\log X)$，空间 $O(n)$。 |

这里 $X=x_n-x_1$ 是初始位置排序后的跨度。前三种做法依次保证前 12、24、40 分；结合特殊性质 A 的做法可保证前 60 分，一般做法覆盖全部 100 分。

枚举值不超过初始位置跨度 $10^8$，可以用 `int` 存储。$n=800$ 时有 $\binom{800}{3}=85013600$ 个值，单次分配约 324.3 MiB；应预先分配足够空间，避免扩容峰值。若改用 `long long` 存这些值，约需 648.6 MiB，会超过空间限制。

$\sum_j L_jR_j$ 的上述判定只用于 $D>0$。答案初值设为 $0$，只二分正阈值；不能把 $D=0$ 直接代入该公式，否则会漏掉终点顺序发生颠倒、最近距离为零的三元组。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 200000 + 10;
struct node{
    long long x,y;
    int id;
}a[N];
int n,t,m,c[N],left_count[N];
long long k,b[N];
bool cmp(node u,node v){
    return u.x < v.x;
}
void add(int x){
    for(int i = x; i <= m; i += i & -i){
        c[i]++;
    }
}
int ask(int x){
    int ans = 0;
    for(int i = x; i > 0; i -= i & -i){
        ans += c[i];
    }
    return ans;
}
long long count(long long d){
    fill(c + 1,c + m + 1,0);
    int p = 1;
    for(int j = 1; j <= n; j++){
        while(p < j && a[p].x <= a[j].x - d){
            add(a[p].id);
            p++;
        }
        int q = upper_bound(b + 1,b + m + 1,a[j].y - d) - b - 1;
        left_count[j] = ask(q);
    }
    fill(c + 1,c + m + 1,0);
    p = n;
    long long ans = 0;
    for(int j = n; j >= 1; j--){
        while(p > j && a[p].x >= a[j].x + d){
            add(a[p].id);
            p--;
        }
        int q = lower_bound(b + 1,b + m + 1,a[j].y + d) - b - 1;
        int right_count = n - p - ask(q);
        ans += 1LL * left_count[j] * right_count;
    }
    return ans;
}
int main(){
    freopen("track.in","r",stdin);
    freopen("track.out","w",stdout);
    ios::sync_with_stdio(false);
    cin.tie(0);
    cin >> n >> t >> k;
    for(int i = 1; i <= n; i++){
        long long v;
        cin >> a[i].x >> v;
        a[i].y = a[i].x + t * v;
        b[i] = a[i].y;
    }
    sort(a + 1,a + n + 1,cmp);
    sort(b + 1,b + n + 1);
    m = unique(b + 1,b + n + 1) - b - 1;
    for(int i = 1; i <= n; i++){
        a[i].id = lower_bound(b + 1,b + m + 1,a[i].y) - b;
    }
    long long need = 1LL * n * (n - 1) * (n - 2) / 6 - k + 1;
    long long l = 1,r = a[n].x - a[1].x,ans = 0;
    while(l <= r){
        long long mid = (l + r) / 2;
        if(count(mid) >= need){
            ans = mid;
            l = mid + 1;
        }else{
            r = mid - 1;
        }
    }
    cout << ans << '\n';
    return 0;
}
```

# T4 按位记录（bits）

---

## 从整数转向数位

---

当 $nk\le16$ 且 $m\le10$ 时，可以枚举每个 $a_i\in[0,2^k)$，检查每个数是否出现相邻的两个 $1$，再检查全部记录。共有 $2^{nk}$ 个候选，直接检查一次需要 $O(n+mn)$ 时间，可获得前 $3$ 个测试点的 $12$ 分。生成候选时只枚举不含相邻 $1$ 的整数，还可以减少搜索量。

按位与、按位或都可以逐位判断，但各位的方案数不能直接相乘。例如样例 1 的两位各有两种选择，乘积为 $4$，其中数字 $3$ 却不合法。相邻两位必须一起考虑。

用一个 $n$ 位掩码 $S$ 表示某个数位上哪些 $a_i$ 为 $1$，第 $i-1$ 位对应位置 $i$。设相邻两个数位的掩码分别为 $T,S$，那么它们能够相接，当且仅当 $T\mathbin{\&}S=0$。更早的数位不再影响这个判断，因此只需保留上一位的掩码。

## 预处理每个数位的记录

---

固定数位 $b$，一条记录对该位的要求只有四种。

| 记录类型 | $x$ 的第 $b$ 位 | 要求 |
| --- | --- | --- |
| `A` | $1$ | 区间内全部为 $1$ |
| `A` | $0$ | 区间内至少有一个 $0$ |
| `O` | $0$ | 区间内全部为 $0$ |
| `O` | $1$ | 区间内至少有一个 $1$ |

把所有必须为 $0$、必须为 $1$ 的位置分别合并成掩码 `force0[b]`、`force1[b]`。

对于右端点相同的“至少有一个 $0$”记录 $[l,r]$，只需保留最大的 $l$：满足最短的这个区间，就一定满足包含它的其他区间。“至少有一个 $1$”同理。分别用 `need0[b][r]`、`need1[b][r]` 记录这个最大左端点，初值 $0$ 表示没有此类限制。

这样预处理需要 $O(km)$ 时间。检查掩码 $S$ 时，先检查强制位，再枚举右端点检查这两类区间，单个掩码只需 $O(n)$ 时间。记检查结果为 $valid_b(S)$。

## 逐位动态规划

---

设 $f_b(S)$ 表示已填写第 $0$ 到第 $b$ 位、当前数位的掩码为 $S$，并且已填写部分满足全部要求的方案数。转移为

$$
f_b(S)=valid_b(S)\sum_{T\mathbin{\&}S=0}f_{b-1}(T).
$$

尚未填写任何数位时，令 $f_{-1}(0)=1$，其他状态为 $0$；按 $b=0,1,\ldots,k-1$ 的顺序更新，最终答案为 $\sum_S f_{k-1}(S)$。最高位之外全为 $0$，无需额外限制。

第 $0$ 位可直接令 $f_0(S)=valid_0(S)$，无需枚举前一位；小规模数据也可沿用前述枚举法。

每个合法序列唯一对应这 $k$ 个掩码。每次转移检查当前位的全部记录，以及它与上一位在每个位置上是否同时为 $1$；这正好覆盖所有条件。因此，合法序列均被计入一次，非法序列不会被计入。

直接枚举 $S,T$，时间为 $O(km+k4^n)$，可覆盖前 $8$ 个测试点，保证 $32$ 分。

令 $all=2^n-1$。条件 $T\mathbin{\&}S=0$ 等价于 $T$ 是 $all\mathbin{\mathtt{xor}}S$ 的子集，因此可以只枚举这些子集。所有 $S$ 的枚举次数之和是

$$
\sum_S2^{n-|S|}=3^n,
$$

因为每个位置只有“属于 $S$”“属于 $T$”“都不属于”三种选择。时间降至 $O(km+k3^n)$，当 $n\le15$ 时可覆盖前 $15$ 个测试点，保证 $60$ 分。

## 合并重复的子集求和

---

上一步会反复累加相同的旧状态。设

$$
g(U)=\sum_{T\subseteq U}f_{b-1}(T),
$$

就可以直接取 $f_b(S)=valid_b(S)\cdot g(all\mathbin{\mathtt{xor}}S)$。

从 $g=f_{b-1}$ 开始，依次处理位置 $i=0,1,\ldots,n-1$。对每个包含位置 $i$ 的掩码 $U$，执行

$$
g(U)\leftarrow g(U)+g(U\setminus\{i\}).
$$

处理前 $i$ 个位置后，$g(U)$ 汇总的是：在已处理位置中，可以任选 $U$ 的子集；在尚未处理位置中，必须与 $U$ 相同。处理位置 $i$ 时，将“选这个位置”和“不选这个位置”两类互斥情况相加。归纳可知，全部位置处理完后，恰好得到所需的全部子集之和。

每个数位用 $O(n2^n)$ 时间算出所有 $g(U)$，再检查各个掩码是否合法并更新。总时间复杂度为 $O(km+kn2^n)$，空间复杂度为 $O(2^n+kn)$。代码中的 `f` 存上一层，`g` 先复制 `f` 再完成累加，因此更新当前层不会破坏需要的旧值。若记录矛盾，相应掩码会被判为非法，最终自然得到 $0$。

## 部分分思路

---

下表分值是题面中各测试点组的分值，各组互不重叠；它不是该行算法能够取得的总分。

| 条件（测试点） | 点组分值 | 做法与复杂度 |
|---|---:|---|
| $nk\le16$ 且 $m\le10$（1–3） | 12 分 | 枚举整个整数序列，检查各整数是否存在相邻的两个 $1$，再逐条检查记录，累计合法序列数。时间 $O(2^{nk}(n+mn))$。 |
| $n\le10$（4–8） | 20 分 | 按数位进行掩码 DP，枚举相邻两列掩码 $T,S$，只累加当前列合法且 $T\mathbin{\&}S=0$ 的转移。时间 $O(km+k4^n)$。 |
| $n\le15$（9–15） | 28 分 | 复用相同状态，将前驱限制为当前掩码补集的子集，只枚举这些子集并求和。时间 $O(km+k3^n)$。 |
| 无额外限制（16–25） | 40 分 | 逐位置累加得到所有子集和，每个当前掩码直接查询其补集对应的和，省去重复求和。时间 $O(km+kn2^n)$。 |

前三点可以沿用完整整数序列枚举；与后续做法结合，累计保证分依次为 12、32、60、100 分。不能仅根据 $n$ 判断前三点属于后续范围，例如 $n=16,k=1$ 也满足 $nk\le16$。按位 DP 的首列可以直接初始化为合法性，后续枚举子集时须包含空子集 $T=0$。

### 参考代码


```cpp
#include<bits/stdc++.h>
using namespace std;
const int MOD = 998244353;
const int N = 18;
const int M = 1 << N;
int n,k,m;
int force0[30],force1[30];
int need0[30][N + 1],need1[30][N + 1];
int f[M],g[M];
// 固定第 b 位，检查掩码 s 是否满足这一位的所有记录。
bool valid(int b,int s){
	if((s & force0[b]) != 0) return false;
	if((s & force1[b]) != force1[b]) return false;
	for(int r = 1; r <= n; r++){
		if(need0[b][r] != 0){
			int l = need0[b][r];
			int mask = ((1 << r) - 1) ^ ((1 << (l - 1)) - 1);
			if((s & mask) == mask) return false;
		}
		if(need1[b][r] != 0){
			int l = need1[b][r];
			int mask = ((1 << r) - 1) ^ ((1 << (l - 1)) - 1);
			if((s & mask) == 0) return false;
		}
	}
	return true;
}
int main(){
	freopen("bits.in","r",stdin);
	freopen("bits.out","w",stdout);
	ios::sync_with_stdio(false);
	cin.tie(0);
	cin >> n >> k >> m;
	for(int j = 1; j <= m; j++){
		char op;
		int l,r,x;
		cin >> op >> l >> r >> x;
		int mask = ((1 << r) - 1) ^ ((1 << (l - 1)) - 1);
		for(int b = 0; b < k; b++){
			int v = (x >> b) & 1;
			if(op == 'A'){
				if(v == 1) force1[b] |= mask;
				else need0[b][r] = max(need0[b][r],l);
			}else{
				if(v == 0) force0[b] |= mask;
				else need1[b][r] = max(need1[b][r],l);
			}
		}
	}
	int all = (1 << n) - 1;
	// 尚未填写任何位时，把前一位视为全 0，空方案只有一种。
	f[0] = 1;
	for(int b = 0; b < k; b++){
		for(int s = 0; s <= all; s++) g[s] = f[s];
		// 逐个位置累加；完成后 g[s] 是所有 t 属于 s 的 f[t] 之和。
		for(int i = 0; i < n; i++){
			for(int s = 0; s <= all; s++){
				if((s & (1 << i)) != 0){
					g[s] += g[s ^ (1 << i)];
					if(g[s] >= MOD) g[s] -= MOD;
				}
			}
		}
		for(int s = 0; s <= all; s++){
			if(valid(b,s)) f[s] = g[all ^ s];
			else f[s] = 0;
		}
	}
	int ans = 0;
	for(int s = 0; s <= all; s++){
		ans += f[s];
		if(ans >= MOD) ans -= MOD;
	}
	cout << ans << '\n';
	return 0;
}
```
