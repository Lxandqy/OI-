# 第 5 套 NOIP 模拟赛题解

# T1 交错对（cross）

---

枚举所有 $i<j$，逐个检查 $a_i<a_j<i$，时间为 $O(n^2)$，能处理前 $4$ 个点。要继续优化，应固定较晚的位置 $j$，把之前的位置对它的贡献统一维护。

设当前查询值为 $x=a_j$。一个已经处理的位置 $i$ 有贡献，当且仅当

$$
a_i<x<i.
$$

也就是说，位置 $i$ 影响的不是某个未来下标，而是一整段可能的查询数值 $[a_i+1,i-1]$。例如 $i=6,a_i=2$ 时，以后查询 $3,4,5$ 都应得到它的一次贡献；查询 $2$ 或 $6$ 则不能得到贡献。这一步将两个数值比较合成了区间上的一次增加。

若数组只有 $D$ 种不同数值，只维护这 $D$ 个可能被查询的值即可。每加入一个位置，逐个判断它是否影响这些数值，再在当前值处取出贡献。排序、去重后，时间为 $O(n\log n+nD)$，能处理前 $10$ 个点。一般数据中 $D$ 可能达到 $n$，重复逐值更新仍会达到二次量级。

维护整个值域也不需要开到 $10^9$：非空更新区间满足 $1\le a_i+1\le i-1<n$；可能得到贡献的查询一定满足 $0<a_j<j$。其余查询答案为 $0$。所以只需维护下标 $1\sim n$。

用差分数组 $b$ 表示目前各数值的贡献。向区间 $[a_i+1,i-1]$ 加 $1$，只需令

$$
b_{a_i+1}\mathrel{+}=1,\qquad b_i\mathrel{-}=1.
$$

查询值 $x$ 的贡献是 $\sum_{v=1}^x b_v$。树状数组支持这两个单点修改和一次前缀求和，每步 $O(\log n)$。

按 $j$ 递增扫描时，**先查询 $a_j$，再加入位置 $j$ 的影响区间**。查询前，结构中恰有全部 $i<j$ 的贡献；每个贡献又恰好检查了 $a_i<a_j<i$，因此既不遗漏合法对，也不会多计。空区间不更新，端点处的相等情况由 $a_i+1$ 与 $i-1$ 排除。

总时间 $O(n\log n)$，空间 $O(n)$。单次查询不超过 $n$，但总答案最多为 $\binom n2$，需要使用 `long long`。

## 部分分思路

---

下表列出各点组的分值；$D$ 表示数组中不同数值的数量。

| 条件 | 分值 | 做法与时间复杂度 |
|---|---:|---|
| $n\le3000$（第 $1\sim4$ 点） | $20$ 分 | 枚举 $i<j$，检查 $a_i<a_j<i$，累计合法对数，$O(n^2)$。 |
| $D\le30$（第 $5\sim10$ 点） | $30$ 分 | 复用正文的贡献区间，只维护实际出现的 $D$ 个查询值；每加入一个位置，逐值增加它的贡献，$O(n\log n+nD)$。 |

逐值维护也能处理前 $4$ 个小规模点，因此覆盖第 $1\sim10$ 点，累计保证 $50$ 分。两个不等式都必须严格；扫描到一个位置时，先查询，再加入这个位置的贡献。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 500010;
int n,a[N],bit[N];
void add(int x,int v){
	for(int i = x; i <= n; i += i & -i) bit[i] += v;
}
int query(int x){
	int ans = 0;
	for(int i = x; i > 0; i -= i & -i) ans += bit[i];
	return ans;
}
int main(){
	freopen("cross.in","r",stdin);
	freopen("cross.out","w",stdout);
	ios::sync_with_stdio(false);
	cin.tie(0);
	cin >> n;
	for(int i = 1; i <= n; i++) cin >> a[i];
	for(int i = 1; i <= n; i++) bit[i] = 0;
	long long ans = 0;
	for(int i = 1; i <= n; i++){
		if(a[i] > 0 && a[i] < i) ans += query(a[i]);
		if(a[i] + 1 < i){
			add(a[i] + 1,1);
			add(i,-1);
		}
	}
	cout << ans << '\n';
	return 0;
}
```


# T2 密码库（password）

---

前 $4$ 个点可以枚举每一位允许的整数，得到一个完整密码后，从左到右扫描库序列判断能否匹配。枚举次数至多 $K^m$，每次检查 $O(n)$。这里枚举的是密码本身，不是匹配下标；否则库为 $(1,1)$ 时，密码 $(1)$ 就会被重复计算。

全部符合位置限制的密码数为

$$
T=\prod_{t=1}^m(r_t-l_t+1).
$$

改为统计其中能匹配的不同密码数 $M$，答案就是 $T-M$。库中不存在的符号不会出现在能匹配的密码里，因此求 $M$ 时只需考虑库中出现的 $D$ 种符号，不用遍历高达 $10^9$ 的整个符号范围。

一个可匹配密码可能有许多匹配下标，先为它指定唯一代表：每一位都在上一匹配位置之后，选择最早出现的位置。若某次匹配选择了更晚的位置，把它替换成更早的同符号位置后，剩余位置仍然可用，所以这个贪心过程成功当且仅当密码可匹配。每个密码也就有唯一的最早匹配终点。

设 $E_t(j)$ 为满足前 $t$ 位限制、最早匹配恰好在位置 $j$ 结束的不同密码数，初始 $E_0(0)=1$。从终点 $j$ 枚举下一位符号，转移到这个符号在 $j$ 之后的第一次出现位置，就能不重不漏地扩展密码。预处理这些后继位置后，时间为 $O(nmD+nD+n\log n)$，空间为 $O(nD+n+m)$，可处理前 $10$ 个点。瓶颈是每个终点都重复枚举同一批符号。

转而固定新的结束位置 $i$，设 $p_i$ 为 $s_i$ 上一次出现的位置，不存在则为 $0$。若追加符号 $s_i$ 的最早新终点是 $i$，前一个最早终点 $j$ 必须满足：

- $p_i>0$ 时，$p_i\le j<i$。若 $j<p_i$，会先匹配到 $p_i$；若 $j\ge p_i$，则 $j$ 之后到 $i$ 之前没有同符号。
- $p_i=0$ 时，$0\le j<i$，并允许空前缀的终点 $j=0$。

于是，同符号的一批转移变成上一层连续终点区间的求和。令

$$
F_t(i)=\sum_{j=0}^i E_t(j),
$$

即满足前 $t$ 位限制、能够匹配库前缀 $s_1,\ldots,s_i$ 的不同密码数。它是终点状态的前缀累计，**并不等于**“恰在 $i$ 结束”的数量。初始化为 $F_0(i)=1$；对于 $t>0$，$F_t(0)=0$。

如果 $s_i$ 不在 $[l_t,r_t]$ 内，不能以它作为第 $t$ 位，因此 $F_t(i)=F_t(i-1)$。否则，最早终点恰为 $i$ 的新增数量是

$$
\Delta_t(i)=
\begin{cases}
F_{t-1}(i-1)-F_{t-1}(p_i-1),&p_i>0,\\
F_{t-1}(i-1),&p_i=0,
\end{cases}
$$

并有 $F_t(i)=F_t(i-1)+\Delta_t(i)$。每个新增密码由唯一的前缀和末位符号确定，终点条件又排除了先前已能匹配的相同密码，所以不会重复。最终 $M=F_m(n)$。

代码中 `pre[i]` 对应 $p_i$，`f[i]` 保存上一长度层，`g[i]` 保存当前长度层。当前层按 $i$ 递增计算，读上一层的两项与本层的 `g[i-1]`；整层结束后才覆盖 `f`，避免混用不同长度。用排序和二分预处理前次出现位置，总时间 $O(nm+n\log n)$，空间 $O(n+m)$。

所有计数都在模意义下维护，减法要加模数后规范化。$m>n$ 时没有可匹配密码，转移自然得到 $F_m(n)=0$；符号重复、允许区间含库外符号也已包含在上述分类中。

## 部分分思路

---

下表列出各点组的分值；$D$ 表示库序列中不同符号的数量，$K$ 是允许符号的上界。

| 条件 | 分值 | 做法与时间复杂度 |
|---|---:|---|
| $n\le20,\ m\le6,\ K\le4$（第 $1\sim4$ 点） | $20$ 分 | 枚举每一位允许的符号，得到完整密码后贪心匹配库序列；不能匹配时计入答案。至多 $K^m$ 个密码，总时间 $O((n+m)K^m)$。 |
| $n\le600,\ m\le100,\ D\le50$（第 $5\sim10$ 点） | $30$ 分 | 记录正文的最早匹配终点状态 $E_t(j)$，枚举下一位允许的库内符号，跳到其后继位置；先求能匹配的不同密码数，再用总数减去它。预处理及 DP 共 $O(nmD+nD+n\log n)$。 |

最早终点 DP 也覆盖前 $4$ 个点，累计保证 $50$ 分。枚举密码时按密码身份计数；在终点 DP 中，库外符号只计入总数，不产生匹配转移，不能因此将它们从总密码数中删掉。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 5010,MOD = 998244353;
int n,m,k,a[N],p[N],pos[N],pre[N],l[N],r[N];
long long f[N],g[N];
int main(){
	freopen("password.in","r",stdin);
	freopen("password.out","w",stdout);
	ios::sync_with_stdio(false);
	cin.tie(0);
	cin >> n >> m >> k;
	for(int i = 1; i <= n; i++){
		cin >> a[i];
		p[i] = a[i];
	}
	long long total = 1;
	for(int i = 1; i <= m; i++){
		cin >> l[i] >> r[i];
		total = total * (r[i] - l[i] + 1) % MOD;
	}
	sort(p + 1,p + n + 1);
	int d = unique(p + 1,p + n + 1) - p - 1;
	for(int i = 1; i <= d; i++) pos[i] = 0;
	for(int i = 1; i <= n; i++){
		int x = lower_bound(p + 1,p + d + 1,a[i]) - p;
		pre[i] = pos[x];
		pos[x] = i;
	}
	for(int i = 0; i <= n; i++) f[i] = 1;
	for(int t = 1; t <= m; t++){
		g[0] = 0;
		for(int i = 1; i <= n; i++){
			g[i] = g[i - 1];
			if(l[t] <= a[i] && a[i] <= r[t]){
				long long value = f[i - 1];
				if(pre[i] > 0) value -= f[pre[i] - 1];
				g[i] = (g[i] + value + MOD) % MOD;
			}
		}
		for(int i = 0; i <= n; i++) f[i] = g[i];
	}
	cout << (total - f[n] + MOD) % MOD << '\n';
	return 0;
}
```


# T3 蛛网传信（spider）

---

先建立一个简单无向图：每只蜘蛛对应一个点，最大公约数大于 $1$ 的点对之间连一条边。显式检查全部点对，BFS 求距离，再按距离递增累计最短路数量，时间为 $O(n^2\log A)$，其中 $A=\max a_i$，可处理前 $4$ 个点。不能将一对点的多个共同质因子当成多条边。

标签相同的点具有相同的外部邻居，只有 $D$ 种标签时，可以把同标签点合成一个类别，在类别间检查 gcd 并建图。起点与终点是同一只蜘蛛时答案为 `0 1`；它们直接相邻时为 `1 1`；标签为 $1$ 的点没有邻居。处理这些边界后，原图的一条最短路不会重复经过同一类别，否则利用相同外部邻居就能删去一段得到更短路线。对某一具体点的路径数，将上一层各类别的“单点路径数乘类别人数”相加即可；起点类别只放起点这一只，终点也只取指定蜘蛛的单点路径数。总时间 $O(n\log n+D^2\log A)$，空间 $O(n+D^2)$，可处理前 $10$ 个点。

一般数据不能枚举点对。将每个 $a_i$ 分解为不同质因子，并把蜘蛛 $i$ 加入这些质因子的桶。两个点有边，当且仅当它们至少出现在同一个桶中。

先只求距离。BFS 弹出蜘蛛 $u$ 时，扫描它所在的每个尚未扫描过的质因子桶，把桶中所有未访问蜘蛛的距离设成 $\operatorname{dist}(u)+1$。BFS 按距离递增弹出点，因此第一次扫描这个桶时，已经找到了桶内可用前驱的最小距离；以后再扫描不可能得到更短距离。每个桶只扫描一次，避免显式生成桶内的团。

但是，计数不能照搬“桶只用一次”。同一层的多个蜘蛛都可能给下一层贡献最短路；而直接把所有共同质因子桶的贡献相加，又会重复。例如标签 $6$ 与 $30$ 之间只有一条边，经因子 $2$ 和 $3$ 累计却会算两次。

距离确定后，最短路必须从距离 $d$ 的点走到距离 $d+1$ 的点。令 $\operatorname{ways}(u)$ 为起点到 $u$ 的最短路线数。对当前层定义

$$
S_d(b)=\sum_{\substack{\operatorname{dist}(u)=d\\b\mid a_u}}\operatorname{ways}(u).
$$

设下一层的点 $v$ 有不同质因子集合 $P(v)$。它的合法前驱是“含有 $P(v)$ 中至少一个质因子”的点集之并，用容斥求并集的总权值：

$$
\operatorname{ways}(v)=
\sum_{\varnothing\ne U\subseteq P(v)}
(-1)^{|U|+1}S_d\!\left(\prod_{p\in U}p\right).
$$

若一个前驱与 $v$ 共有 $k\ge1$ 个不同质因子，它被计入的总系数为

$$
\sum_{h=1}^k(-1)^{h+1}\binom kh=1.
$$

没有共同质因子的点系数为 $0$。因此每条实际的前驱边恰好贡献一次，再在其后追加 $v$，恰好得到全部不同最短编号序列。

初始只有 $\operatorname{ways}(s)=1$。处理每一层时，先遍历本层所有点，将它们的路径数加入每个非空质因子子集乘积对应的 `sum`；整层加入完成后，再用上述公式计算下一层。`mark[b]` 记录 `sum[b]` 属于哪一层，第一次在本层使用时清零，查询旧层标记则视为 $0$。这样不必每层清空整个值域，也不会把新算出的下一层贡献提前加入。

代码中的 `factor[i]` 只保存不同质因子，`make_divisors` 枚举它们的子集乘积，并同时生成容斥符号。$A\le300000$ 时，一个数至多有 $6$ 个不同质因子，因为最小的 $7$ 个质数之积 $510510>A$，故连同空集最多 $64$ 个子集；所有乘积也不超过原数。

筛最小质因子耗时 $O(A\log\log A)$；分解所有标签耗时 $O(n\log A)$；桶 BFS 共扫描 $O(\sum_i\omega(a_i))$ 项；计数最多对每个点的子集各加入、查询一次。总时间为

$$
O\!\left(A\log\log A+n\log A+\sum_i2^{\omega(a_i)}\right),
$$

空间为 $O(A+n+\sum_i\omega(a_i))$。不可达时直接输出 `-1 0`；$s=t$ 时计数循环不执行，保留初值 `0 1`。标签 $1$ 的质因子集合为空，正好不会产生边。

## 部分分思路

---

下表列出各点组的分值；$D$ 是不同标签的数量，$A=\max a_i$。

| 条件 | 分值 | 做法与时间复杂度 |
|---|---:|---|
| $n\le500$（第 $1\sim4$ 点） | $20$ 分 | 检查全部点对的 gcd，建立简单图，再用 BFS 求最短距离并按层累计路径数，$O(n^2\log A)$。 |
| $D\le1200$（第 $5\sim10$ 点） | $30$ 分 | 将同标签蜘蛛归为一类，检查类别之间的 gcd；BFS 后，用上一层每类的单点路径数乘该类人数进行转移，$O(n\log n+D^2\log A)$。 |

类别做法也覆盖前 $4$ 个点，累计保证 $50$ 分。起点类只以指定起点的 $1$ 条空路线初始化；终点输出指定蜘蛛的单点路径数，不再乘终点类人数。$s=t$、直接相邻和标签为 $1$ 的情况按正文先处理；同一对点有多个共同质因子，仍只有一条边。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 300010,MOD = 998244353;
int n,a[N],spf[N],dist[N],ways[N],sum[N],mark[N];
bool used[N];
vector<int> factor[N],bucket[N],layer[N];
int divisors[64],signs[64];
int make_divisors(int x){
	int size = 1;
	divisors[0] = 1;
	signs[0] = -1;
	for(int i = 0; i < (int)factor[x].size(); i++){
		int old = size;
		for(int j = 0; j < old; j++){
			divisors[size] = divisors[j] * factor[x][i];
			signs[size] = -signs[j];
			size++;
		}
	}
	return size;
}
int main(){
	freopen("spider.in","r",stdin);
	freopen("spider.out","w",stdout);
	ios::sync_with_stdio(false);
	cin.tie(0);
	cin >> n;
	int bound = 1;
	for(int i = 1; i <= n; i++){
		cin >> a[i];
		bound = max(bound,a[i]);
	}
	int s,t;
	cin >> s >> t;
	for(int i = 1; i <= n; i++){
		factor[i].clear();
		layer[i - 1].clear();
		dist[i] = -1;
		ways[i] = 0;
	}
	for(int i = 0; i <= bound; i++){
		spf[i] = 0;
		bucket[i].clear();
		used[i] = false;
		mark[i] = -1;
	}
	for(int i = 2; i <= bound; i++){
		if(spf[i] != 0) continue;
		for(int j = i; j <= bound; j += i){
			if(spf[j] == 0) spf[j] = i;
		}
	}
	for(int i = 1; i <= n; i++){
		int x = a[i];
		while(x > 1){
			int p = spf[x];
			factor[i].push_back(p);
			bucket[p].push_back(i);
			while(x % p == 0) x /= p;
		}
	}
	queue<int> q;
	dist[s] = 0;
	q.push(s);
	while(!q.empty()){
		int x = q.front();
		q.pop();
		layer[dist[x]].push_back(x);
		for(int j = 0; j < (int)factor[x].size(); j++){
			int p = factor[x][j];
			if(used[p]) continue;
			used[p] = true;
			for(int z = 0; z < (int)bucket[p].size(); z++){
				int y = bucket[p][z];
				if(dist[y] != -1) continue;
				dist[y] = dist[x] + 1;
				q.push(y);
			}
		}
	}
	if(dist[t] == -1){
		cout << "-1 0\n";
		return 0;
	}
	ways[s] = 1;
	for(int d = 0; d < dist[t]; d++){
		for(int z = 0; z < (int)layer[d].size(); z++){
			int x = layer[d][z],size = make_divisors(x);
			for(int j = 1; j < size; j++){
				int v = divisors[j];
				if(mark[v] != d){
					mark[v] = d;
					sum[v] = 0;
				}
				sum[v] += ways[x];
				if(sum[v] >= MOD) sum[v] -= MOD;
			}
		}
		for(int z = 0; z < (int)layer[d + 1].size(); z++){
			int x = layer[d + 1][z],size = make_divisors(x);
			long long value = 0;
			for(int j = 1; j < size; j++){
				int v = divisors[j];
				if(mark[v] == d) value += 1LL * signs[j] * sum[v];
			}
			ways[x] = (value % MOD + MOD) % MOD;
		}
	}
	cout << dist[t] << ' ' << ways[t] << '\n';
	return 0;
}
```


# T4 树上调和（tree）

---

前 $4$ 个点可以枚举每个顶点的整数取值，再计算全部边的费用。每点至多有 $4$ 种取值，时间为 $O(n\cdot4^n)$。一般数据不宜只枚举区间两端：若两个点的区间分别为 $[1,9]$ 和 $[5,5]$，最优值为 $0$，第一个点必须取内部的 $5$。

先设 $f_u(x)$ 为固定 $x_u=x$ 时，$u$ 子树内的最小费用；区间外的状态不可行。按孩子分别选择根值，有

$$
f_u(x)=\sum_{v\text{ 是 }u\text{ 的孩子}}\min_{y\in[l_v,r_v]}\bigl(f_v(y)+|x-y|\bigr),
\qquad x\in[l_u,r_u].
$$

叶子在允许区间内的值为 $0$。若值域上界为 $V$，逐对枚举每条边的父子取值，时间 $O(nV^2)$，可处理前 $8$ 个点。

对某个孩子，复制其状态为 $g$，先递增扫描令 $g(x)\gets\min(g(x),g(x-1)+1)$，再递减扫描令 $g(x)\gets\min(g(x),g(x+1)+1)$。第一次传播所有 $y\le x$ 的 $f_v(y)+x-y$，第二次补齐所有 $y\ge x$ 的 $f_v(y)+y-x$，恰好求出绝对值转移。每条边只扫描两遍，降为 $O(nV)$，可处理前 $12$ 个点。

值域很大时，也可先压缩全体区间端点。相邻端点之间没有允许区间的边界，把落在这段开区间内的所有取值一起向左或向右平移，在触碰端点之前始终合法；内部边的费用不变，对外的边费用是线性函数，至少一个移动方向不会增加总费用。移动到有取值触及端点，重复即可得到全部取值都在端点上的最优解。设不同端点数为 $K$，坐标为 $q_1<\cdots<q_K$，两次扫描分别加上 $q_i-q_{i-1}$ 与 $q_{i+1}-q_i$，不能按压缩后的秩差加 $1$。时间为 $O(nK+n\log n)$，在 $K\le20$ 的第 $13$ 个点也能通过；但一般数据中 $K$ 可能达到 $2n$，还需继续优化。

全局坐标表还维护了许多与当前子树无关的端点，可以改为每棵子树只保存自己的端点表。先明确父亲看到孩子的是经过一条边转移后的函数

$$
h_u(x)=\min_{y\in[l_u,r_u]}\bigl(f_u(y)+|x-y|\bigr).
$$

把整数位置的函数值作线性延拓。叶子的 $h_u$ 是到 $[l_u,r_u]$ 的距离，各段斜率依次为 $-1,0,1$。归纳地，孩子函数相加得到 $f_u$，各段斜率仍为单调不减的整数；限制到 $[l_u,r_u]$ 只会新增这两个端点。再作绝对值转移时，斜率大于 $1$ 的部分可通过把 $y$ 向左移来降低 $f_u(y)+|x-y|$，斜率小于 $-1$ 时同理向右移；直到已有斜率变化点或允许端点为止。因此转移把斜率限制在 $[-1,1]$，不会在原有线性段内部产生新折点。所有折点都是子树中的区间端点；这些端点是整数，整数 $x$ 的转移也能在整数 $y$ 处取得最小值。

于是可用有序的“坐标、函数值”表完整保存 $h_u$：相邻坐标之间线性插值，最左、最右坐标之外分别按斜率 $-1,1$ 外推。合并两个孩子时，归并它们的坐标表，在并集的每个坐标上分别求值后相加。随后插入 $l_u,r_u$，删去允许区间外的坐标，得到 $f_u$ 的表；最后按真实坐标差做前述两遍扫描，得到 $h_u$。这里保留整个局部表，即使相邻若干段的斜率相同，也不必再删除中间坐标。

第 $15$ 个点每个顶点至多有两个孩子。一次合并和转移的时间与子树内保留的端点数成正比；一个原始端点只会出现在所属顶点及其祖先的表中。若树的深度为 $h$，总时间为 $O(nh)$，所以 $h\le20$ 时可以处理。按编号倒序计算，并在合并后释放孩子的表，同时存活的表对应互不相交的子树，空间为 $O(n)$。这也避免了全局 $K$ 很大时为每个子树重复扫描无关端点。不过一般深树中，许多历史端点可能一直保留，表长之和仍可达到二次量级。

还要继续问：父亲是否真的需要孩子的全部状态？局部表已经去掉子树外的坐标，还可以在每次绝对值转移后删除共线的中间坐标。由前面的整数斜率性质，转移后的斜率只可能依次为 $-1,0,1$，所以有效折点只有常数个。每个孩子传来的表大小为 $O(1)$，在有 $k$ 个孩子的顶点按表长从小到大归并，费用为 $O(k\log(k+1))$；合并、限域、转移后再删去共线点，全树总时间为 $O(n\log n)$。这已经是一种完整的满分做法。前面的 $O(nh)$ 阶段指保留冗余端点的实现，删除共线点则进一步消除了深度带来的瓶颈。

为了让状态和合并公式更简洁，下面直接用最小费用和取得它的整个区间描述这个常数大小的函数，并推导中位区间合并。

记 $c_u$ 为 $f_u$ 的最小值，全部取得最小值的根值为整数区间 $[L_u,R_u]$。关键结论是

$$
h_u(x)=c_u+\operatorname{dist}(x,[L_u,R_u]),
$$

其中 $\operatorname{dist}(x,[L,R])$ 表示 $x$ 到区间的距离：区间内为 $0$，左侧为 $L-x$，右侧为 $x-R$。

为什么仅保留这个区间足够？对叶子，$f_u$ 在自身区间内恒为 $0$，结论成立。若孩子已经满足结论，则 $f_u$ 是若干“到区间的距离”之和，再限制在自己的允许区间内。每一项的相邻差分单调不减，且是整数；它们的和也具有这两个性质。因此 $f_u$ 的最小值位置连续，离开最优区间后，每移动一格至少增加 $1$，从而对每个可行的 $y$ 都有

$$
f_u(y)\ge c_u+\operatorname{dist}(y,[L_u,R_u]).
$$

距离的三角不等式给出

$$
f_u(y)+|x-y|\ge c_u+\operatorname{dist}(x,[L_u,R_u]).
$$

另一方面，取最优区间内离 $x$ 最近的 $y$，就能达到这个下界。这证明了压缩公式，并完成从叶子向上的归纳。这里使用了边费用的系数为 $1$ 和整数差分；也必须保留**全部**最优根值区间，随意选其中一个值会损失与父亲连接时的选择。

现在考虑如何合并。设 $u$ 有 $k$ 个孩子，先加上它们的 $c_v$，剩下只需在 $[l_u,r_u]$ 中最小化

$$
\sum_v\operatorname{dist}(x,[L_v,R_v]).
$$

利用恒等式

$$
\operatorname{dist}(x,[L,R])=
\frac{|x-L|+|x-R|-(R-L)}2,
$$

去掉与 $x$ 无关的常数后，就是到 $2k$ 个端点的绝对值距离之和。将端点排序为 $e_1\le\cdots\le e_{2k}$：在 $e_k$ 左边，左侧端点少于一半，向右移动会减少费用；在 $e_{k+1}$ 右边同理；中间两侧数目各为一半，费用不变。因此无约束最优根值恰为 $[e_k,e_{k+1}]$。

再限制到 $[l_u,r_u]$。若两区间相交，取交集；若不相交，则靠近无约束最优区间的那个允许端点最优。实现上，将 $e_k,e_{k+1}$ 各自夹到 $[l_u,r_u]$ 内，就得到 $L_u,R_u$。任选其中一个值（代码取 $L_u$）计算所有孩子区间到它的距离，再加孩子的 $c_v$，即得 $c_u$。叶子单独设 $[L_u,R_u]=[l_u,r_u]$、$c_u=0$。

第 $14$ 个点保证所有 $2\le i\le n$ 都有 $p_i=i-1$，树是一条链。此时每点至多有一个孩子，上述合并不需要排序，只需求两个区间的间距并夹取端点，时间 $O(n)$。将链的处理与全局端点坐标 DP 结合，可覆盖前 $14$ 个点；进一步使用保留冗余端点的子树局部表，便能覆盖第 $15$ 个点，累计 $75$ 分。一般深树可继续通过每次转移后删除共线坐标来求解；下面的参考代码采用完整最优区间和中位区间公式，直接完成同一函数的常数大小表示与合并。

代码中 `lo[u],hi[u],dp[u]` 分别对应 $L_u,R_u,c_u$。由于 $p_i<i$，按 $n,n-1,\ldots,1$ 处理时，每个孩子已经计算完毕，无需额外建立遍历序。根没有向上的边，答案就是 `dp[1]`。

若每点的孩子数为 $k_u$，排序总时间为 $O(\sum_u k_u\log(k_u+1))\subseteq O(n\log n)$；其余合并共 $O(n)$，空间 $O(n)$。总费用最多为 $(n-1)(10^9-1)$，需要使用 `long long`。

## 部分分思路

---

下表列出各点组的分值。$V=\max r_i$，$K$ 为全部区间端点中不同数值的数量，$h$ 为树深度，根的深度为 $1$。

| 条件 | 分值 | 做法与时间复杂度 |
|---|---:|---|
| $n\le8,\ r_i\le4$（第 $1\sim4$ 点） | $20$ 分 | 枚举每个顶点的合法整数取值，计算全部边的费用并取最小，$O(n4^n)$。 |
| $n\le500,\ r_i\le60$（第 $5\sim8$ 点） | $20$ 分 | 用正文的 $f_u(x)$，逐条边枚举父子两端取值，计算最小费用，$O(nV^2)$。 |
| $n\le10000,\ r_i\le3000$（第 $9\sim12$ 点） | $20$ 分 | 同一 DP 的绝对值转移改为递增、递减两遍扫描，每条边 $O(V)$，共 $O(nV)$。 |
| $K\le20$（第 $13$ 点） | $5$ 分 | 只在全局不同端点上做双扫描 DP，扫描时加真实坐标距离，$O(nK+n\log n)$。 |
| $p_i=i-1$，整棵树为链（第 $14$ 点） | $5$ 分 | 从链尾向根传递最小费用和全部最优值区间；每点只合并一个孩子，求区间间距并夹取端点即可，$O(n)$。 |
| 每点至多两个孩子，$h\le20$（第 $15$ 点） | $5$ 分 | 按正文保存子树局部端点表，归并孩子坐标，限制到本点允许区间，再按真实距离双扫描。每个端点只沿祖先链保留，共 $O(nh)$。 |

前三种算法依次覆盖前 $4$、$8$、$12$ 点，对应累计保证 $20$、$40$、$60$ 分。全局端点 DP 可再覆盖第 $13$ 点，累计 $65$ 分；配合链的做法可达 $70$ 分，再配合浅二叉树的局部表可达 $75$ 分。后三档是不同性质，应按满足的条件选择对应算法。

局部表这一档保留冗余端点，一般深树仍可能达到二次量级；若每次转移后删除共线坐标，就成为正文已经说明的满分做法。压缩坐标后始终使用真实数值差，最优根值也必须保留完整区间。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 200010;
int n,l[N],r[N],lo[N],hi[N];
long long dp[N];
vector<int> son[N];
int clamp_value(int x,int left,int right){
	return min(right,max(left,x));
}
int main(){
	freopen("tree.in","r",stdin);
	freopen("tree.out","w",stdout);
	ios::sync_with_stdio(false);
	cin.tie(0);
	cin >> n;
	for(int i = 1; i <= n; i++) son[i].clear();
	for(int i = 2; i <= n; i++){
		int p;
		cin >> p;
		son[p].push_back(i);
	}
	for(int i = 1; i <= n; i++) cin >> l[i] >> r[i];
	for(int x = n; x >= 1; x--){
		dp[x] = 0;
		if(son[x].empty()){
			lo[x] = l[x];
			hi[x] = r[x];
			continue;
		}
		vector<int> ends;
		for(int j = 0; j < (int)son[x].size(); j++){
			int y = son[x][j];
			ends.push_back(lo[y]);
			ends.push_back(hi[y]);
			dp[x] += dp[y];
		}
		sort(ends.begin(),ends.end());
		int k = son[x].size();
		lo[x] = clamp_value(ends[k - 1],l[x],r[x]);
		hi[x] = clamp_value(ends[k],l[x],r[x]);
		for(int j = 0; j < (int)son[x].size(); j++){
			int y = son[x][j];
			if(lo[x] < lo[y]) dp[x] += lo[y] - lo[x];
			if(lo[x] > hi[y]) dp[x] += lo[x] - hi[y];
		}
	}
	cout << dp[1] << '\n';
	return 0;
}
```
