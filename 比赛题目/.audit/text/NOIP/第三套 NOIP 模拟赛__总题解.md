# 第三套 NOIP 模拟赛题解

训练卷

# T1 环线协作（relay）

---

先按熟练工人计数，记第 $i$ 名工人有 $c_i$ 项自己的任务。同一人的任务去向规则完全相同，只需决定其中多少项交给下一人。直接做法是逐项搜索任务交给自己还是下一人，维护各人的工时与当前最大工时，回溯时恢复负载；每个分支只修改一个人的工时，耗时 $O(1)$。搜索树有 $O(2^m)$ 个节点，连同读入和初始化，总时间为 $O(n+m+2^m)$，可处理 $n\le12,m\le18$。

## 固定时限后，尽量少给下一人增加负担

---

假设要在 $T$ 小时内完成，令 $x_i$ 表示第 $i$ 名工人交给下一人的任务数。他自己处理 $c_i-x_i$ 项，还要处理上一人交来的 $x_{i-1}$ 项，故必须满足
$$
0\le x_i\le c_i,\qquad c_i-x_i+2x_{i-1}\le T.
$$
这组限制沿环相互依赖。题目保证存在 $c_p=0$，此人不可能转出自己的任务，所以 $x_p=0$ 已经确定。从 $p$ 的下一人开始，顺时针处理，最后再处理 $p$，即可把环变成一条有确定起点的依赖链。

给定上一人的转出量，当前人至少需要转出
$$
x_i=\max(0,c_i+2x_{i-1}-T).
$$
取更大的数只会增加下一人的负担，因此就取这个最小值。若它超过 $c_i$，说明即使把自己的任务全部转走，也不能按时处理收到的任务，判定失败。

为什么局部取最少不会丢失可行方案？从 $x_p=0$ 开始，与任意可行方案逐项比较：若贪心收到的任务不更多，则它所需转出的最少数量也不更多。归纳可得贪心的每个 $x_i$ 都不大于可行方案对应的数。因此贪心若违反上界，任何方案都会违反；若最终通过，刚才构造的各个数量本身就是可行分配。最后处理空工人 $p$，也就检查了环上的最后一条限制。

## 从判定得到最优时刻

---

增大 $T$ 不会让原有分配失效。下界为 $1$；让每个人只做自己的任务，总能在 $m$ 小时内完成。因此在 $[1,m]$ 中二分第一个可行值。

代码中的 $x$ 在每轮开始时是上一人的转出量，更新后变为当前人的转出量。每次判定从 $0$ 重新开始，不能把上一次二分留下的值带入下一次。时间复杂度为 $O(m+n\log(m+1))$，空间复杂度为 $O(n)$。

## 部分分思路

---

下表分值是题面各点组的分值。

| 条件 | 分值 | 做法 |
|---|---:|---|
| $n\le12,\ m\le18$（第1--4点） | 20 分 | 逐项搜索任务交给自己还是下一人，维护各人工时及当前最大工时，回溯时恢复被修改的工时；完整分配时用当前最大工时更新答案。每个分支只修改一人的负载，耗时 $O(1)$，总时间为 $O(n+m+2^m)$。 |
| $n,m\le2000$（第5--8点） | 20 分 | 沿用正文的空工人断环和最少转出判定，从 $T=1$ 到 $m$ 依次尝试，第一次可行即为答案。每次判定 $O(n)$，连同读入计数共 $O(m+nm)$。 |
| $n=2$（第9--10点） | 10 分 | 至少一人没有自己的任务，因此全部任务只有一个来源。转出 $x$ 项时，两人的工时为 $m-x$ 和 $2x$，最小化两者的最大值，答案为 $\lceil2m/3\rceil$。读入为 $O(m)$，此后计算为 $O(1)$。 |

两个工人的完成时刻 $T$ 满足 $3T\ge2(m-x)+2x=2m$，而取 $x=\lfloor m/3\rfloor$ 恰能达到 $\lceil2m/3\rceil$，所以该公式是最优值。

前两组范围有包含关系：逐时限判定也能完成第1--4点，先覆盖前八点的 $40$ 分。当 $n=2$ 时，它的总时间降为 $O(m)$，因此这一算法本身就保证前十点，共 $50$ 分。公式可以将两个工人的情形在读入后的计算降为 $O(1)$，但不再增加逐时限法的保证分；若仅组合小规模枚举和该公式，则保证 $30$ 分。公式只适用于题目保证下的两个工人，不能推广到多个任务来源。正文的二分法完成全部测试点，得到 $100$ 分。

```cpp
const int N = 500010;
int n,m,c[N],p;
bool check(int t){
	int x = 0;
	for(int j = 1; j <= n; j++){
		int i = (p + j - 1) % n + 1;
		x = max(0,c[i] + 2 * x - t);
		if(x > c[i]) return false;
	}
	return true;

	ios::sync_with_stdio(false);
	cin.tie(0);

	for(int i = 1; i <= n; i++) c[i] = 0;
	for(int i = 1; i <= m; i++){
		int x;
		cin >> x;
		c[x]++;
	}

		if(c[i] == 0){
			p = i;
			break;
		}
	}

		int mid = (l + r) / 2;
		if(check(mid)) r = mid;
		else l = mid + 1;
	}
	cout << l << '\n';
	return 0;
}
```

# T2 双点巡查（watch）

---

先考虑检查点可以放在哪里。一个点若覆盖了一些区间，将它左移到这些区间左端点的最大值，仍不会离开任何一个已覆盖区间。因此存在最优方案，两个点都在某个区间的左端点上；移动后重新按左右排序即可。没有覆盖区间的点可以舍去。

将不同左端点排序为 $p_1<\cdots<p_k$。直接枚举两个候选点，再逐区间累加被覆盖的权值，是 $O(n^3)$ 的做法。困难在于两个点的贡献不能直接相加：同时包含它们的区间会被重复计算。

## 固定右点，把区间分成互不重复的两类

---

固定较右的检查点为 $p_i$，较左的点记为 $y\le p_i$。令 $C_i$ 为所有包含 $p_i$ 的区间权值和，这部分可以先全部计入。

一个不包含 $p_i$、却包含 $y$ 的区间，必有 $r<p_i$。因为它包含 $y\le p_i$，左端点不可能在 $p_i$ 右边；不包含 $p_i$ 就只能是右端点已在它左边。反之，所有 $r<p_i$ 的区间都不会贡献给右点，能由左点覆盖的价值可以放心追加。

于是固定右点时的最优值为
$$
C_i+\max_j\sum_{\substack{l_t\le p_j\le r_t\\r_t<p_i}}w_t.
$$
两类区间互斥，而且包含了被两个点覆盖的所有区间。第二项允许为 $0$，所以只设置一个点的情况也已包含。已经结束的区间不会覆盖 $p_i$ 及其右边的位置，式中的最大值即使对全部候选点取，也不会多算。

## 右点移动时，每个区间只加入一次

---

用差分计算 $C_i$。对区间 $[l_t,r_t]$，在候选坐标中找到它覆盖的下标范围 $[L_t,R_t]$，对差分数组的 $L_t$ 加 $w_t$，对 $R_t+1$ 减 $w_t$，前缀和即为 $C_i$。

再将区间按 $R_t$ 排序。从左到右扫描 $i$，把所有满足 $R_t<i$ 的区间加入数据结构：候选下标 $[L_t,R_t]$ 上的值都增加 $w_t$。每个候选位置维护的正是“已经结束的区间中，能被该点覆盖的总价值”。区间加入一次后永不删除，用线段树支持区间加和全局最大值即可。

所有叶子初始为 $0$。处理完 $R_t<i$ 的加入事件后，用 $C_i$ 加树根最大值更新答案。这里必须是严格小于：$r_t=p_i$ 时该区间仍包含右点，不能再次加入左点的贡献。

参考代码把一个区间的整段加值保留在该节点的 `tag` 中，不下推。节点的 `mx` 等于两个孩子最大值再加自己的 `tag`；整段更新同时增加二者。这足以维护全局最大值，因为不需要查询单点或子区间。

时间复杂度 $O(n\log n)$，空间复杂度 $O(n)$。权值和最多为 $2\times10^{14}$，差分、线段树和答案都使用 `long long`。

## 部分分思路

---

下表分值是题面各点组的分值。

| 条件 | 分值 | 做法 |
|---|---:|---|
| $n\le14$（第1--4点） | 20 分 | 枚举两个区间左端点作为检查点，再逐区间判断是否包含至少一个点；每个区间只累加一次权值。允许两点相同，以包含只设一个点的情况。时间为 $O(n^3)$。 |
| $n\le8000$（第5--8点） | 20 分 | 沿用正文对右点贡献与已结束区间贡献的分解，改用普通数组维护各候选左点的价值。每个已结束区间对其覆盖的候选位置逐格加权，更新时顺便维护最大值，再与当前右点贡献相加。时间为 $O(n^2)$。 |
| 任意两个区间都没有公共点（第9--10点） | 10 分 | 一个点至多覆盖一个区间，扫描求出最大的两个权值并相加；若只有一个区间，只取它。时间为 $O(n)$。 |

逐格法兼容第1--4点，先保证前八点的 $40$ 分；在两两不交时，每个区间只覆盖自己的左端点候选，逐格更新总量降为 $O(n)$，连同排序为 $O(n\log n)$，因此该方法本身就保证前十点的 $50$ 分，已经包含性质点组的 $10$ 分。若仅组合两点枚举和不交特判，则保证 $30$ 分。逐格法仍须先加入所有满足 $r<p_i$ 的区间，再计算右点为 $p_i$ 时的答案；端点相等时不能提前加入。正文的线段树方法完成全部测试点，得到 $100$ 分。

## 参考代码

---

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 200010;
struct node{
	int l,r;
	long long w;
}a[N];
int n,k,p[N];
long long b[N],c[N],mx[N * 4],tag[N * 4];
bool cmp(node x,node y){
	return x.r < y.r;
}
void add(int x,int l,int r,int ql,int qr,long long v){
	if(ql <= l && r <= qr){
		mx[x] += v;
		tag[x] += v;
		return;
	}
	int mid = (l + r) / 2;
	if(ql <= mid) add(x * 2,l,mid,ql,qr,v);
	if(qr > mid) add(x * 2 + 1,mid + 1,r,ql,qr,v);
	mx[x] = max(mx[x * 2],mx[x * 2 + 1]) + tag[x];
}
int main(){
	freopen("watch.in","r",stdin);
	freopen("watch.out","w",stdout);
	ios::sync_with_stdio(false);
	cin.tie(0);
	cin >> n;
	for(int i = 1; i <= n; i++){
		cin >> a[i].l >> a[i].r >> a[i].w;
		p[i] = a[i].l;
	}
	sort(p + 1,p + n + 1);
	k = unique(p + 1,p + n + 1) - p - 1;
	for(int i = 1; i <= k + 1; i++) b[i] = 0;
	for(int i = 1; i <= n; i++){
		a[i].l = lower_bound(p + 1,p + k + 1,a[i].l) - p;
		a[i].r = upper_bound(p + 1,p + k + 1,a[i].r) - p - 1;
		b[a[i].l] += a[i].w;
		b[a[i].r + 1] -= a[i].w;
	}
	c[0] = 0;
	for(int i = 1; i <= k; i++) c[i] = c[i - 1] + b[i];
	sort(a + 1,a + n + 1,cmp);
	for(int i = 1; i <= 4 * k; i++){
		mx[i] = 0;
		tag[i] = 0;
	}
	long long ans = 0;
	int j = 1;
	for(int i = 1; i <= k; i++){
		while(j <= n && a[j].r < i){
			add(1,1,k,a[j].l,a[j].r,a[j].w);
			j++;
		}
		ans = max(ans,c[i] + mx[1]);
	}
	cout << ans << '\n';
	return 0;
}
```


# T3 回文通路（palpath）

---

先固定一条通路。它不重复经过格子，所以序列中不同的对称位置对不会共享格子。若一对格子的原值相同，不翻转即可；若不同，只需翻转其中较便宜的一个。因此这一对的最小费用为
$$
c(x,y,u,v)=
\begin{cases}
0,&a_{x,y}=a_{u,v},\\
\min(w_{x,y},w_{u,v}),&a_{x,y}\ne a_{u,v}.
\end{cases}
$$
这给出了直接做法：枚举全部单调通路，逐对计算费用，再取最小值。共有 $\binom{n+m-2}{n-1}$ 条通路，每条用 $O(n+m)$ 时间计算费用，总时间为 $O(\binom{n+m-2}{n-1}(n+m))$，可以处理 $n,m\le5$。但不能把整条反对角线统一修改：题目只要求存在一条通路，其他格子不必满足同样的对称要求。

## 从两端同时决定通路

---

回文条件把首尾两格绑定，再把第二格与倒数第二格绑定。依这个顺序选路，比单端前进后再回看整个序列更自然。

可以先定义四维状态 $F(x,y,u,v)$：从 $(x,y)$ 到 $(u,v)$ 的单调通路成为回文所需的最小费用。首端向右或下走一步，尾端向左或上走一步，内侧有四种组合；取它们的最小值，再加当前两端的费用 $c$。只有首端在尾端左上方的状态合法；两端重合时费用为 $0$，相邻时直接付这对端点的费用。按子矩形的高、宽递增计算，时间和空间均为 $O(n^2m^2)$，可以完成 $n,m\le30$。

这个表计算了很多本题用不到的子矩形。从原起点和终点同步向中间走时，两端已走步数总是相同。设为 $t$，首端行号为 $x$，尾端行号为 $u$，则列号已被唯一确定：
$$
y=t+2-x,\qquad v=n+m-t-u.
$$
因此不必保留四个独立坐标。

## 按层累计，直到两端相遇

---

令 $f_t[x][u]$ 表示两端各走了 $t$ 步、分别停在上述两格时，已经处理的所有外侧对称格子对的最小费用，包含当前这对。它按处理顺序累计费用，与四维 $F$ 的“剩余子矩形费用”含义不同；两者都在枚举同一批完整通路，只是求值方向不同。

初始化 $f_0[1][n]=c(1,1,n,m)$，其余状态为无穷大。当前首端若从上面走来，上一层行号为 $x-1$，否则为 $x$；尾端若从下面走来，上一层行号为 $u+1$，否则为 $u$。故
$$
f_t[x][u]=c(x,y,u,v)+\min\left\{
\begin{array}{ll}
f_{t-1}[x][u],&f_{t-1}[x-1][u],\\
f_{t-1}[x][u+1],&f_{t-1}[x-1][u+1]
\end{array}\right\}.
$$
越界状态和不能继续连接的状态不参与转移。具体要求 $1\le y,v\le m$、$x\le u$、$y\le v$；后两项保证两端之间仍能用向右、向下的步子连接。

记 $D=n+m-2$。处理到 $t=\lfloor D/2\rfloor$ 后，$D$ 为偶数时两端重合，为奇数时两端相邻。对所有合法终态取最小值就是答案。每条完整通路都对应一条这样的状态链；反过来，合法终态中的两半通路可以接成完整通路。各格子对独立付费，中央单格费用为 $0$，因此没有漏算、重复收费或额外约束。

转置网格可以让行数为 $\min(n,m)$，只交换原矩形中位于主对角线下方的格子与其转置位置，耗时 $O(nm)$。参考代码用完整的三维数组 `f[t][x][u]` 保存每一层：先将各层及下标为 $0$、$n+1$ 的边界状态设为无穷大，再按 $t$ 递增计算，每次只读取第 $t-1$ 层。最大层号为 $\lfloor(350+350-2)/2\rfloor=349$，因此第一维预留 $350$ 层。

总时间复杂度为 $O((n+m)\min(n,m)^2)$，DP 与网格所需空间为 $O((n+m)\min(n,m)^2+nm)$。代码预留 `f[350][355][355]`，连同原值和费用数组约占 $338$ MiB，在 $512$ MiB 限制内。最多有 $349$ 对格子付费，每对费用不超过 $10^9$，所以答案不超过 $349\times10^9$，使用 `long long`。

## 部分分思路

---

下表列出题面各点组的分值；这些点组对应的测试点互不重叠，同一种算法可以覆盖多组。

| 条件 | 分值 | 做法 |
|---|---:|---|
| $n,m\le5$（测试点 1–4） | 20 分 | 枚举从左上角到右下角的全部单调通路。对每条通路，按正文的对称格子对费用 $c$ 求和，再对所有通路取最小值。共有 $\binom{n+m-2}{n-1}$ 条通路，时间为 $O\!\left(\binom{n+m-2}{n-1}(n+m)\right)$。 |
| $n,m\le30$（测试点 5–8） | 20 分 | 沿用前文的四维状态 $F(x,y,u,v)$，按子矩形的高、宽递增计算。对合法的四种内侧端点组合取最小值，再加当前两端费用；答案为 $F(1,1,n,m)$。时间、空间均为 $O(n^2m^2)$，也能覆盖测试点 1–4。 |
| $n=1$ 或 $m=1$（测试点 9–10） | 10 分 | 通路唯一，无须选择路线。从序列首尾向中间逐对累加费用 $c$，中央单格不收费，时间为 $O(n+m)$。 |

枚举通路时，单行或单列也只产生一条通路，因此枚举法本身可以保证覆盖测试点 1–4、9–10，共 **30 分**。四维 DP 覆盖测试点 1–8；单行或单列时，其表也只有 $O((n+m)^2)$ 的规模，在本题范围内可直接计算，因此该方法本身保证前十点，共 **50 分**。若对唯一通路单独逐对计算，则可把这类输入的处理降到线性时间。

这些是按点组条件得到的保证分。超出相应范围后，枚举法的通路数可能指数增长，四维表也可能超过时间或空间限制；完整范围采用正文的同步三维 DP。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 355,T = 350;
const long long INF = 4000000000000000000LL;
int n,m,a[N][N];
long long w[N][N],f[T][N][N];
long long cost(int x,int y,int u,int v){
	if(a[x][y] == a[u][v]) return 0;
	return min(w[x][y],w[u][v]);
}
int main(){
	freopen("palpath.in","r",stdin);
	freopen("palpath.out","w",stdout);
	ios::sync_with_stdio(false);
	cin.tie(0);
	cin >> n >> m;
	for(int i = 1; i <= n; i++){
		for(int j = 1; j <= m; j++) cin >> a[i][j];
	}
	for(int i = 1; i <= n; i++){
		for(int j = 1; j <= m; j++) cin >> w[i][j];
	}
	if(n > m){
		for(int i = 1; i <= n; i++){
			for(int j = 1; j <= m && j < i; j++){
				swap(a[i][j],a[j][i]);
				swap(w[i][j],w[j][i]);
			}
		}
		swap(n,m);
	}
	int d = n + m - 2;
	for(int t = 0; t <= d / 2; t++){
		for(int x = 0; x <= n + 1; x++){
			for(int u = 0; u <= n + 1; u++) f[t][x][u] = INF;
		}
	}
	f[0][1][n] = cost(1,1,n,m);
	for(int t = 1; t <= d / 2; t++){
		for(int x = 1; x <= n; x++){
			int y = t + 2 - x;
			if(y < 1 || y > m) continue;
			for(int u = x; u <= n; u++){
				int v = n + m - t - u;
				if(v < y || v > m) continue;
				long long pre = min(f[t - 1][x][u],f[t - 1][x - 1][u]);
				pre = min(pre,f[t - 1][x][u + 1]);
				pre = min(pre,f[t - 1][x - 1][u + 1]);
				if(pre != INF) f[t][x][u] = pre + cost(x,y,u,v);
			}
		}
	}
	long long ans = INF;
	for(int x = 1; x <= n; x++){
		int y = d / 2 + 2 - x;
		if(y < 1 || y > m) continue;
		for(int u = x; u <= n; u++){
			int v = n + m - d / 2 - u;
			if(v < y || v > m) continue;
			ans = min(ans,f[d / 2][x][u]);
		}
	}
	cout << ans << '\n';
	return 0;
}
```

# T4 朋友圈（circle）

---

每个连通块只贡献其中最大的编号。直接在每次查询时遍历整张图，找出所有连通块并将各块的最大编号相加，即可得到答案。连续没有修改的查询可以复用答案。

只有加入时，可以直接用并查集合并，并维护每块的最大编号及这些最大值的总和；只有删除时，先处理完全部删除，再倒序将被删边加回来。一般数据同时有加入和删除，普通并查集不能直接把一个集合拆开，单纯倒序也仍会遇到删除。

## 把“删除”换成一段有效时间

---

操作提前全部给出，可以离线处理。将第 $i$ 次操作后的状态看作时间 $i$。一条初始边从时间 $1$ 起存在；在时间 $l$ 加入、时间 $r$ 删除的边，其有效区间为 $[l,r-1]$。一直没有删除的边有效到 $q$。同一对端点再次加入时，应建立一个新的有效区间。

在时间轴 $[1,q]$ 上建线段树，把每个有效区间分解到 $O(\log q)$ 个完整节点中。在某个节点暂时加入保存于此的全部边，再分别处理左右孩子。抵达时间 $i$ 的叶子时，根到叶的节点恰好保存了当时所有有效边：每条区间覆盖 $i$ 的边恰出现一次，不覆盖的边不会出现。

这把困难变成了：完成一个孩子以后，如何恢复处理它之前的连通状态，以免它的边影响另一个孩子？

## 记录合并造成的变化，原样撤销

---

并查集根记录集合大小 `sz` 和最大编号 `mx`。维护所有根的 `mx` 之和为 `ans`；初始没有边，每个人都是单独一块，所以
$$
ans=1+2+\cdots+n=\frac{n(n+1)}2.
$$
合并不同集合 $A,B$ 时，先从答案减去两块的最大编号，再加上合并后的最大编号。总和只需做这三次更新；若两点原本同块，答案和并查集都不变，也不产生撤销记录。

按集合大小合并，把小集合的根接到大集合的根。合并前记录：两个根、父根的原大小、原最大编号，以及原总和。撤销时让子根重新成为根，再恢复父根的大小、最大值和总和。子根原有的大小与最大值从未改变，不需要另存。

这里不做路径压缩：一次查找若改动了沿途许多父指针，就不能只靠合并记录完整恢复。按大小合并已经保证树高为 $O(\log n)$，足够使用。代码中的 `stk` 只保存需要撤销的合并记录；它不模拟 DFS，时间树仍使用普通递归遍历。

进入时间树节点时，先记住记录栈长度，加入该节点的边，再处理叶子查询或两个孩子；离开前不断撤销，直到栈恢复到原长度。因此每个孩子看到的并查集只包含自身和祖先的边，不受兄弟分支影响。结合有效区间的覆盖性质，每次查询得到的就是当前图的连通块代表编号和。

每个有效区间存入 $O(\log q)$ 个节点，每次合并需要 $O(\log n)$ 的根查找。加上维护边加入时间的有序映射，总时间为 $O(n+(m+q)\log(q+1)\log(n+1))$，空间为 $O(n+q+(m+q)\log(q+1))$。时间树递归深度为 $O(\log q)$；答案上界为 $n(n+1)/2$，须用 `long long`。

## 部分分思路

以下分值是题面各测试点组的分值，按点独立计分。

| 条件 | 测试点与分值 | 做法与时间复杂度 |
|---|---|---|
| $n\le9,\ q\le24$ | 1–4：20 分 | 维护当前边集，每次查询用 DFS 或 BFS 找出所有连通块，累加各块最大编号。任一时刻至多有 $m+q$ 条边，总时间为 $O(q(n+m+q))$。 |
| $n\le200,\ q\le500$ | 5–8：20 分 | 仍可在查询时遍历当前图并累加各块最大编号，时间为 $O(q(n+m+q))$。同一个遍历算法同时覆盖前两组，共 40 分。 |
| 没有类型 $2$ 的操作 | 9–10：10 分 | 先合并初始边，再正序处理新增边。沿用正文“减去原两块最大编号、加上合并后最大编号”的更新，每次查询直接输出维护的总和。按大小合并并使用路径压缩，总时间为 $O(n+(m+q)\alpha(n))$。 |
| 没有类型 $1$ 的操作 | 11–12：10 分 | 用有序集合求出全部删除结束后的边集，先建立此时的并查集；再倒序处理，将删除改为合并并记录查询答案，最后按原顺序输出。总时间为 $O(n+(m+q)\log(m+q+1)+(m+q)\alpha(n))$。 |
| 无额外限制 | 13–20：40 分 | 将每条边的每段有效时间分配到时间线段树；遍历节点时合并其边，离开时撤销，叶子处取得对应查询答案。沿用正文的可回滚并查集，总时间为 $O(n+(m+q)\log(q+1)\log(n+1))$。 |

其中 $\alpha$ 为反阿克曼函数。按输入是否只含新增、是否只含删除选择对应的并查集做法，其余输入使用查询遍历，可以覆盖第 1–12 点，保证 60 分。最后一行的 40 分仅指第 13–20 点的分值；时间线段树加可回滚并查集同时覆盖全部点，保证 100 分。

正序或逆序的单向操作方法不需要撤销，因此可以使用路径压缩；正文的回滚方法仍只按大小合并，不能直接加入路径压缩。同一对端点在一般数据中多次出现时，每次加入到下一次删除之间都要单独建立有效区间。

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 100010,Q = 200010;
struct node{
	int x,y,s,m;
	long long ans;
};
int n,m,q,fa[N],sz[N],mx[N],op[Q];
long long ans;
vector<pair<int,int> > v[Q * 4];
vector<node> stk;
map<pair<int,int>,int> st;
int find(int x){
	while(fa[x] != x) x = fa[x];
	return x;
}
void merge(int x,int y){
	x = find(x);
	y = find(y);
	if(x == y) return;
	if(sz[x] < sz[y]) swap(x,y);
	node t;
	t.x = x;
	t.y = y;
	t.s = sz[x];
	t.m = mx[x];
	t.ans = ans;
	stk.push_back(t);
	ans -= mx[x] + mx[y];
	fa[y] = x;
	sz[x] += sz[y];
	mx[x] = max(mx[x],mx[y]);
	ans += mx[x];
}
void add(int x,int l,int r,int ql,int qr,pair<int,int> e){
	if(ql > qr) return;
	if(ql <= l && r <= qr){
		v[x].push_back(e);
		return;
	}
	int mid = (l + r) / 2;
	if(ql <= mid) add(x * 2,l,mid,ql,qr,e);
	if(qr > mid) add(x * 2 + 1,mid + 1,r,ql,qr,e);
}
void dfs(int x,int l,int r){
	int k = stk.size();
	for(int i = 0; i < (int)v[x].size(); i++){
		merge(v[x][i].first,v[x][i].second);
	}
	if(l == r){
		if(op[l] == 3) cout << ans << '\n';
	}else{
		int mid = (l + r) / 2;
		dfs(x * 2,l,mid);
		dfs(x * 2 + 1,mid + 1,r);
	}
	while((int)stk.size() > k){
		node t = stk.back();
		stk.pop_back();
		fa[t.y] = t.y;
		sz[t.x] = t.s;
		mx[t.x] = t.m;
		ans = t.ans;
	}
}
int main(){
	freopen("circle.in","r",stdin);
	freopen("circle.out","w",stdout);
	ios::sync_with_stdio(false);
	cin.tie(0);
	cin >> n >> m;
	st.clear();
	stk.clear();
	for(int i = 1; i <= m; i++){
		int x,y;
		cin >> x >> y;
		if(x > y) swap(x,y);
		st[make_pair(x,y)] = 1;
	}
	cin >> q;
	for(int i = 1; i <= 4 * q; i++) v[i].clear();
	for(int i = 1; i <= q; i++){
		cin >> op[i];
		if(op[i] == 3) continue;
		int x,y;
		cin >> x >> y;
		if(x > y) swap(x,y);
		pair<int,int> e = make_pair(x,y);
		if(op[i] == 1) st[e] = i;
		else{
			add(1,1,q,st[e],i - 1,e);
			st.erase(e);
		}
	}
	map<pair<int,int>,int>::iterator it;
	for(it = st.begin(); it != st.end(); it++){
		add(1,1,q,it->second,q,it->first);
	}
	st.clear();
	ans = 1LL * n * (n + 1) / 2;
	for(int i = 1; i <= n; i++){
		fa[i] = i;
		sz[i] = 1;
		mx[i] = i;
	}
	dfs(1,1,q);
	return 0;
}
```
