# 接龙（chain）

## 【题目描述】

牛牛有 $n$ 张牌，第 $i$ 张牌上的数字为 $a_i$。他可以任意调整这些牌的放置顺序，然后依次把牌放到桌面一列的末尾。

每放置一张牌后，他可以进行至多一次收牌操作：从桌面上选择两张数字相同的牌，收走这两张牌以及它们之间的所有牌。若这两张相同的牌数字为 $x$，本次共收走 $len$ 张牌，则获得

$$x\times len$$

分。被收走的牌不会再次使用。牛牛也可以在某一回合不收牌。

求把所有牌都放置完以后，能够获得的最大总分。

## 【输入格式】

第一行输入一个正整数 $n$。

第二行输入 $n$ 个正整数 $a_1,a_2,\ldots,a_n$。

## 【输出格式】

输出一行一个整数，表示最大总分。

## 【样例 1 输入】

```text
4
3 3 4 4
```

## 【样例 1 输出】

```text
16
```

## 【样例 2 输入】

```text
3
1 2 3
```

## 【样例 2 输出】

```text
0
```

## 【样例 3 输入】

```text
3
5 5 5
```

## 【样例 3 输出】

```text
15
```

## 【样例 5】

## 【数据范围】

- $1\le n\le10^5$；
- $1\le a_i\le10^5$。

本题共 $10$ 个测试点，每点 $10$ 分，下列前几类独立计分。

# 平方和（sumsq）

## 【题目描述】

给定 $n$ 个正整数。请选择两个**不同位置**的数字 $a_i,a_j$，令

$$x=a_i^2+a_j^2。$$

要求 $x$ 能被 $k$ 整除，并使 $x$ 尽可能大。输入保证至少存在一组合法选择。

## 【输入格式】

第一行包含两个正整数 $n,k$。

第二行包含 $n$ 个正整数 $a_1,a_2,\ldots,a_n$。

## 【输出格式】

输出最大的合法平方和。

## 【样例 1 输入】

```text
5 2
1 2 3 4 5
```

## 【样例 1 输出】

```text
34
```

## 【样例 2 输入】

```text
5 10
1 2 3 4 5
```

## 【样例 2 输出】

```text
20
```

## 【样例 3】

见下发文件中的 `sumsq/sumsq3.in` 与 `sumsq/sumsq3.ans`。本组为公开大样例，不计入正式测试点。

## 【样例 4】

见下发文件中的 `sumsq/sumsq4.in` 与 `sumsq/sumsq4.ans`。本组为公开大样例，不计入正式测试点。

## 【数据范围】

- $1\le n\le2\times10^5$；
- $1\le k\le10^9$；
- $1\le a_i\le10^9$；
- 保证存在两个不同位置组成合法答案。

本题共 $10$ 个测试点，每点 $10$ 分，下列前几类独立计分。

# 彩彩的三彩项链（necklace）

## 【题目描述】

彩彩有一条首尾相连、长度为 $n$ 的项链。每颗珠子的颜色是红、绿、蓝之一，分别用字符 `r`、`g`、`b` 表示。

一次点击可以把一颗珠子的颜色按照以下顺序改变一次：

```text
r -> g -> b -> r
```

可以多次点击同一颗珠子。

彩彩希望修改后，项链上任意两颗相邻珠子的颜色都不同。由于项链首尾相连，第 $1$ 颗珠子和第 $n$ 颗珠子也相邻。

求最少点击次数。

## 【输入格式】

第一行输入一个整数 $n$。

第二行输入一个长度为 $n$ 的字符串 $s$。

## 【输出格式】

输出最少点击次数。

## 【样例 1 输入】

```text
3
rrr
```

## 【样例 1 输出】

```text
3
```

# 表达式（eval）

## 【题目描述】

给定一个只由正整数、加号 `+` 和乘号 `*` 组成的合法表达式 $S$。

你可以在表达式中的任意合法位置添加任意多对括号，但不能改变数字和运算符的原有顺序。求能够得到的最大表达式值。

## 【输入格式】

一行一个字符串 $S$。

## 【输出格式】

输出一行一个正整数，表示最大值。答案可能非常大，需要输出完整十进制表示。

## 【样例 1 输入】

```text
1*2+2*1
```

## 【样例 1 输出】

```text
4
```

## 【样例 2 输入】

```text
1*2345+6789*9867+5432*1
```

## 【样例 2 输出】

```text
139741066
```

## 【样例说明】

样例 1 可以变为 $1\times(2+2)\times1=4$。

样例 2 可以变为

$$(1\times2345+6789)\times(9867+5432\times1)
=1\times(2345+6789)\times(9867+5432)\times1。$$

## 【样例 3】

见下发文件中的 `eval/eval3.in` 与 `eval/eval3.ans`。本组为公开大样例，不计入正式测试点。

## 【样例 4】

见下发文件中的 `eval/eval4.in` 与 `eval/eval4.ans`。本组为公开大样例，不计入正式测试点。

## 【数据范围】

设 $|S|$ 为字符串长度，$n$ 为正整数个数，第 $i$ 个数为 $a_i$。

- $1\le|S|\le5\times10^3$；
- $1\le n\le\lceil |S|/2\rceil$；
- $1\le a_i<10^{|S|}$。

本题共 $20$ 个测试点，每点 $5$ 分。
