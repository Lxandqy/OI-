# 回文串（palindrome）

## 【题目描述】

给定一个字符串 $s$。你可以任意重排其中的字符，求重排后回文子串数量的最大值。

子串必须连续且非空。一个字符串正着读与反着读相同，就称为回文串，单个字符也是回文串。

按子串的位置区间计数：即使内容相同，只要起点或终点不同，就视为不同子串。例如 `aa` 有两个单字符回文子串和一个长度为 $2$ 的回文子串。

## 【输入格式】

输入一行字符串 $s$。

## 【输出格式】

输出一个整数，表示最多的回文子串数量。

## 【样例 1 输入】

```text
abca
```

## 【样例 1 输出】

```text
5
```

## 【样例 1 解释】

可以排列成 `aabc`，回文子串为两个 `a`、一个 `b`、一个 `c` 和一个 `aa`，共 $5$ 个。

## 【样例 2 输入】

```text
aa
```

## 【样例 2 输出】

```text
3
```

## 【样例 2 解释】

两个 `a` 和一个 `aa`，共 $3$ 个。

# 交错四元组（quad）

## 【题目描述】

给定一个长度为 $n$ 的整数数组 $a$，从左到右选择四个位置 $i<j<k<l$，要求

$$a_i<a_k<a_j<a_l.$$

求满足条件的下标四元组数量。四个不等号中的比较均为严格比较。数组可以包含相等元素；不同的下标选择分别计数。

## 【输入格式】

第一行一个整数 $n$。第二行 $n$ 个整数 $a_1,\ldots,a_n$。

## 【输出格式】

输出一个整数，表示合法选择的数量。

## 【样例 1 输入】

```text
4
1 3 2 4
```

## 【样例 1 输出】

```text
1
```

## 【样例 2 输入】

```text
5
1 2 3 4 5
```

## 【样例 2 输出】

```text
0
```

## 【样例 3 输入】

```text
5
1 4 2 3 5
```

## 【样例 3 输出】

```text
2
```

## 【样例 3 解释】

合法下标组为 $(1,2,3,5)$ 和 $(1,2,4,5)$，答案为 $2$。

# 文件判定（files）

## 【题目描述】

一次练习赛有四道题。选手的提交目录必须满足以下规则，请判断给出的全部文件关系是否合法。

1. 只有一个根目录。根目录名称由一段非空英文字母和一段非空数字依次连接而成，例如 `BJ01`；`123`、`ABC`、`A2B` 都不合法。
2. 根目录中恰好有四个题目文件夹，每个题目名称是非空的纯英文字母串。
3. 每个题目文件夹恰好包含一个条目，名称必须为“题目名称 + `.cpp`”，并且该条目不能再有子条目。
4. 大小写敏感。不能出现多余文件或多余目录。只判断名称和包含关系，不区分文件与文件夹的真实类型。

例如，合法目录可以是：

```text
BJ01
  apple / apple.cpp
  Banana / Banana.cpp
  candy / candy.cpp
  task / task.cpp
```

输入中的每条关系 $A\ B$ 表示 $B$ 是 $A$ 的直接子条目。关系不一定按目录层次顺序给出。

## 【输入格式】

第一行正整数 $t$，表示数据组数。

每组数据先给出正整数 $n$，表示关系条数。接下来 $n$ 行，每行两个字符串 $A,B$。

同一名称表示同一个条目，保证同名条目不会出现在目录的不同位置；给出的关系不重复，并且 $A\ne B$。

## 【输出格式】

每组输出一行 `yes` 或 `no`。

## 【样例 1 解释】

# 树与叶子（leafcut）

## 【题目描述】

给定一棵 $n$ 个点的无根树。一个点的度是与它直接相连的点数。本题将度不超过 $1$ 的点定义为叶子，因此孤立的单个点也是叶子。

删除树中的一条边后，树分成两个连通部分。分别按照删除后的度数，统计两部分的叶子数量 $L_1,L_2$。

求 $|L_1-L_2|$ 的最小值，以及有多少条边在删除后能达到这个最小值。

## 【输入格式】

第一行正整数 $T$。每组先输入整数 $n$，接下来 $n-1$ 行，每行两个整数 $u,v$，表示一条无向边。

## 【输出格式】

每组输出两个非负整数：最小叶子数量差值，以及达到该差值的断边方案数。

## 【样例 1 输入】

```text
2
4
1 2
2 3
2 4
4
2 1
1 3
3 4
```

## 【样例 1 输出】

```text
1 3
0 1
```

## 【样例 1 解释】

第一组无论删除哪条边，都是一个孤点和一棵三点小树，叶子数分别为 $1,2$，所以输出 `1 3`。第二组是一条四点链，只有删去中间边能让两边各有两个叶子。

## 【样例 3】

见下发文件中的 `leafcut/leafcut3.in` 与 `leafcut/leafcut3.ans`。本组为公开大样例，不计入正式测试点。

## 【数据范围】
