# 染布（dye）

## 【题目描述】

染坊有 $n$ 块布，按 $1$ 到 $n$ 的顺序等待染色。第 $i$ 块布允许使用的染料编号为 $l_i$ 到 $r_i$ 之间的任意整数，包括两个端点。

需要将这些布划分成若干个非空的连续批次，每块布恰好属于一批，顺序不能改变。每批使用同一种染料，必须适合批内的每一块布。

请问最少需要分成多少个批次？

## 【输入格式】

从文件 `dye.in` 中读入数据。

第一行包含一个整数 $n$，表示布的数量。

接下来 $n$ 行，每行包含两个整数 $l_i,r_i$，表示第 $i$ 块布允许的染料编号范围。

## 【输出格式】

输出到文件 `dye.out` 中。

输出一个整数，表示最少需要的批次数。

## 【样例 1 输入】

```text
3
1 3
3 5
4 6
```

## 【样例 1 输出】

```text
2
```

## 【样例 1 解释】

前两块布使用 $3$ 号染料，第三块布单独使用 $4$ 号染料，共分两批。三块布没有共同允许的染料，因此不能只分一批。

## 【样例 2 输入】

```text
3
2 7
5 5
1 5
```

## 【样例 2 输出】

```text
1
```

## 【样例 3】

见下发文件 `dye/dye3.in` 与 `dye/dye3.ans`。该样例满足测试点 $1\sim 8$ 的限制。

## 【样例 4】

见下发文件 `dye/dye4.in` 与 `dye/dye4.ans`。该样例满足测试点 $9\sim 20$ 的限制。

## 【数据范围】

对于所有测试数据，保证 $1\le n\le 2\times 10^5$，$1\le l_i\le r_i\le 10^9$。

| 测试点编号 | $n\le$ |
|:-:|:-:|
| $1\sim 8$ | $2000$ |
| $9\sim 20$ | $2\times 10^5$ |

# 工坊互助（workshop）

## 【题目描述】

霜叶工坊要制作一批纪念章。工坊里有 $n$ 名工人，第 $i$ 名工人原本负责 $a_i$ 件任务。每件任务都可以交给任意一名工人完成，但不能拆分给多名工人。

工人完成自己原本负责的一件任务需要 $1$ 分钟。第 $i$ 名工人完成其他工人原本负责的一件任务需要 $b_i$ 分钟；如果他至少接手一件这样的任务，还需要额外花费 $c_i$ 分钟做准备。无论接手多少件其他人的任务，这段准备时间都只需要花费一次。只完成自己的任务时，不需要准备。

所有工人都从时刻 $0$ 开始工作，可以同时工作。同一名工人的任务和准备工作依次进行，不能同时进行；任务可以按任意顺序完成。

请合理分配所有任务，使全部任务完成的时刻尽可能早，求这个最早时刻。

## 【输入格式】

从文件 `workshop.in` 中读入数据。

第一行包含一个整数 $n$，表示工人数。

接下来 $n$ 行，第 $i$ 行包含三个整数 $a_i,b_i,c_i$，依次表示第 $i$ 名工人原本负责的任务数、完成一件其他人的任务所需的时间，以及接手其他人的任务所需的一次准备时间。

## 【输出格式】

输出到文件 `workshop.out` 中。

输出一个整数，表示全部任务最早能在第几分钟完成。

## 【样例 1 输入】

```text
3
9 4 2
1 2 1
0 3 0
```

## 【样例 1 输出】

```text
6
```

## 【样例 1 解释】

第一名工人完成自己的 $6$ 件任务，用时 $6$ 分钟；第二名工人完成自己的 $1$ 件任务，并接手第一名工人的 $2$ 件任务，用时 $1+1+2\times2=6$ 分钟；第三名工人接手第一名工人的 $1$ 件任务，用时 $3$ 分钟。因此，全部任务在第 $6$ 分钟完成。

如果要求在第 $5$ 分钟完成，第一名工人至少需要交出 $4$ 件任务，另外两名工人在完成本职任务后各至多接手 $1$ 件，无法完成全部任务。

## 【样例 2 输入】

```text
2
8 2 0
0 2 3
```

## 【样例 2 输出】

```text
7
```

## 【样例 2 解释】

第一名工人完成自己的 $7$ 件任务，第二名工人接手剩余的 $1$ 件，用时 $3+2=5$ 分钟，全部任务在第 $7$ 分钟完成。

若第一名工人只做 $6$ 件，第二名工人需要接手 $2$ 件，用时 $3+2\times2=7$ 分钟，仍不能在第 $6$ 分钟完成。

## 【样例 3】

见下发文件 `workshop/workshop3.in` 与 `workshop/workshop3.ans`。这组样例满足测试点 $5\sim8$ 的限制。

## 【样例 4】

见下发文件 `workshop/workshop4.in` 与 `workshop/workshop4.ans`。这组样例满足测试点 $9\sim20$ 的限制。

## 【数据范围】

对于所有测试数据，保证 $1\le n\le2\times10^5$，$0\le a_i,c_i\le10^9$，$2\le b_i\le10^9$，且 $\sum_{i=1}^{n}a_i\ge1$。

本题共 $20$ 个测试点，每个测试点 $5$ 分，各测试点独立计分。

| 测试点编号 | $n\le$ | $a_i\le$ |
|:-:|:-:|:-:|
| $1$ | $1$ | $10^9$ |
| $2\sim4$ | $2$ | $10^9$ |
| $5\sim8$ | $1000$ | $1000$ |
| $9\sim20$ | $2\times10^5$ | $10^9$ |

# 灯带（lantern）

## 【题目描述】

校园秋日展览需要布置一条灯带。灯带从左到右有 $n+m$ 个位置，需要恰好安装 $n$ 盏红灯和 $m$ 盏蓝灯。

有些位置的颜色已经确定，不能修改；其余位置可以自由选择红色或蓝色。为了让颜色分布更加丰富，任意一段连续同色的灯都不能超过 $k$ 盏。

请你计算满足要求的颜色安排有多少种。两种安排不同，当且仅当至少一个位置的颜色不同。答案可能很大，请输出答案对 $10^9+7$ 取模的结果。如果不存在满足要求的安排，输出 $0$。

## 【输入格式】

从文件 `lantern.in` 中读入数据。

第一行包含三个整数 $n,m,k$。

第二行包含一个长度为 $n+m$ 的字符串 $s$。字符串只包含 `R`、`B` 和 `?`：`R` 表示该位置必须安装红灯，`B` 表示必须安装蓝灯，`?` 表示该位置可以自由选择颜色。

## 【输出格式】

输出到文件 `lantern.out` 中。

输出一个整数，表示满足要求的安排数量对 $10^9+7$ 取模的结果。

## 【样例 1 输入】

```text
2 2 2
R???
```

## 【样例 1 输出】

```text
3
```

## 【样例 1 解释】

三种安排分别为 `RRBB`、`RBRB` 和 `RBBR`。

## 【样例 2 输入】

```text
3 2 1
?R???
```

## 【样例 2 输出】

```text
0
```

## 【样例 2 解释】

由于 $k=1$，相邻位置的颜色必须不同。恰好使用三盏红灯、两盏蓝灯时，唯一可能的颜色顺序为 `RBRBR`，但第二个位置已经固定为红色，因此没有满足要求的安排。

## 【样例 3】

见下发文件 `lantern/lantern3.in` 与 `lantern/lantern3.ans`。这组样例满足测试点 $8\sim12$ 的限制。

## 【样例 4】

见下发文件 `lantern/lantern4.in` 与 `lantern/lantern4.ans`。这组样例满足测试点 $13\sim20$ 的限制。

## 【数据范围】

对于所有测试数据，保证 $1\le n,m\le2000$，$1\le k\le n+m$。字符串 $s$ 的长度为 $n+m$，且只包含 `R`、`B` 和 `?`。

本题共 $20$ 个测试点，每个测试点 $5$ 分，按测试点独立计分。

| 测试点编号 | 附加限制 |
|:-:|:-:|
| $1\sim4$ | $n+m\le22$ |
| $5\sim7$ | $k=1$ |
| $8\sim12$ | $n,m\le120$ |
| $13\sim20$ | 无 |

# 高台（plateau）

## 【题目描述】

霜叶展的场地被划分成 $n$ 行 $m$ 列的方格，第 $i$ 行第 $j$ 列方格中已经堆放了高度为 $a_{i,j}$ 的积木。

小满想在场地中选择两个连续的正方形区域，分别搭建两座展台。这两个区域的边界都与方格边界重合，边长均为同一个正整数 $L$，每个区域恰好包含 $L$ 行 $L$ 列方格。两个区域不能包含同一个方格，但可以有公共边界。

为了让展台足够稳固，这两个区域内每个方格的积木高度都必须至少为 $L$。小满可以向这些方格添加积木，每使用一块积木，恰好使一个方格的高度增加 $1$。原本高度超过 $L$ 的方格可以保持原样。

两座展台合计至多还能使用 $B$ 块积木。请你求出能够满足要求的公共边长 $L$ 的最大值。如果无法选出符合要求的两个区域，输出 $0$。

## 【输入格式】

从文件 `plateau.in` 中读入数据。

第一行包含三个整数 $n,m,B$，分别表示场地的行数、列数和还能使用的积木数量。

接下来 $n$ 行，每行包含 $m$ 个整数。其中第 $i$ 行的第 $j$ 个整数为 $a_{i,j}$。

## 【输出格式】

输出到文件 `plateau.out` 中。

输出一个整数，表示符合要求的两座展台的公共边长的最大值；如果不存在，输出 $0$。

## 【样例 1 输入】

```text
3 4 5
1 3 0 5
2 1 4 2
0 2 3 1
```

## 【样例 1 输出】

```text
2
```

## 【样例 1 解释】

第一座展台选择前两行、前两列，向其中两个高度为 $1$ 的方格各添加一块积木；第二座展台选择前两行、后两列，向其中高度为 $0$ 的方格添加两块积木。两个区域没有公共方格，合计使用 $4$ 块积木，不超过 $5$ 块。

场地中无法放下两个没有公共方格的边长为 $3$ 的正方形，因此答案为 $2$。

## 【样例 2 输入】

```text
1 1 100
7
```

## 【样例 2 输出】

```text
0
```

## 【样例 2 解释】

场地中只有一个方格，无法放下两座展台。

## 【样例 4】

见下发文件 `plateau/plateau4.in` 与 `plateau/plateau4.ans`。这组样例满足测试点 $11\sim20$ 的限制。

## 【数据范围】

对于所有测试数据，保证 $1\le n,m\le2000$，$0\le B\le10^{15}$，$0\le a_{i,j}\le10^9$。

每个测试点 $5$ 分。
