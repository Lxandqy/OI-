# 第三套 NOIP 模拟赛题解

# T1 环线协作（relay）

---

知识点：二分答案、贪心

工人同时开工，决定完工时刻的是**工作时间最长的那个人**。直接安排任务时，给当前工人减负，可能正好压垮下一人。不妨先给每人相同的上限 $T$ 小时，只问能否排得下：某个 $T$ 能做到，更长的时限也能做到。于是可以二分最小的可行 $T$。下面只需解决一次判定。

**上一人转来的任务，必须先给它们留出时间。** 记 $c_i$ 为以工人 $i$ 为熟练工人的任务数。假设上一人转来 $x$ 项，它们已经交给了第二个也是最后一个合法负责人，工人 $i$ 必须花 $2x$ 小时完成。若 $2x>T$，即使他不做任何自己的任务也来不及。否则他还剩 $T-2x$ 小时，每小时能做一项自己的任务；做不完的才需要交给下一人。所以他**至少**要转出

$$
y=\max(0,c_i-(T-2x)).
$$

为什么敢只转这 $y$ 项？多转一项会让下一人额外花两小时。更一般地，拿任意可行分配作对照：如果它让当前工人收到的任务不少于 $x$ 项，那么它必须转出的数量也至少是 $y$，因为上式随 $x$ 增大而不减。只要双方从同一个已知的转出量出发，这个比较就能逐人传下去：我们在每一步转出的都不会比它更多。

**从谁之后开始？** 题面保证至少有一人 $p$ 没有自己的任务。他可能要帮上一人干活，却无论如何都不能往下转，所以他的转出量恰好是 $0$。从 $p$ 的下一人开始，带着 $x=0$ 绕环一周；每次用 $y$ 替换 $x$。若 $y>c_i$，正好意味着 $2x>T$：连收到的任务都放不下，而其他分配不可能让他收到更少的任务，故判定失败。必须把 $p$ 也作为**最后一人**检查一次；若全部通过，最后的转出量因 $c_p=0$ 仍为 $0$，沿途选出的数量就给出一份合法分配。这里的先后只是计算顺序，各工人仍同时开工。

看题面样例，四人的任务数为 $(3,2,0,1)$。试 $T=2$，从空工人 $3$ 的下一人开始：$4$ 号不用转；$1$ 号来不及做完三项，要转一项；$2$ 号光是帮 $1$ 号就用完两小时，只能把自己的两项全转出。最后 $3$ 号虽然没有自己的任务，却需要四小时帮忙，所以 $T=2$ 不行。取 $T=3$ 时各做各的即可，答案是 $3$。

因为 $m\ge1$，答案至少是 $1$；所有任务由熟练工人自己完成，至多需要 $m$ 小时。在 $[1,m]$ 内二分，每次判定扫描 $n$ 人，总时间 $O(m+n\log(m+1))$，空间 $O(n)$。

### 参考代码

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 500010;
int n,m,c[N],p;
bool check(int t){
	int x = 0;
	for(int j = 1; j <= n; j++){
		int i = (p + j - 1) % n + 1;
		x = max(0,c[i] + 2 * x - t);
		if(x > c[i]) return false;
	}
	return true;
}
int main(){
	freopen("relay.in","r",stdin);
	freopen("relay.out","w",stdout);
	ios::sync_with_stdio(false);
	cin.tie(0);
	cin >> n >> m;
	for(int i = 1; i <= n; i++) c[i] = 0;
	for(int i = 1; i <= m; i++){
		int x;
		cin >> x;
		c[x]++;
	}
	for(int i = 1; i <= n; i++){
		if(c[i] == 0){
			p = i;
			break;
		}
	}
	int l = 1,r = m;
	while(l < r){
		int mid = (l + r) / 2;
		if(check(mid)) r = mid;
		else l = mid + 1;
	}
	cout << l << '\n';
	return 0;
}
```

# T2 双点巡查（watch）

---

知识点：扫描线、差分、线段树

样例 1 中，检查点 $4$ 单独能得到 $7+6+2=15$，点 $7$ 单独能得到 $9+2=11$。两点一起只能得到 $24$：价值为 $2$ 的长区间 $[1,8]$ 在两笔账里各算了一次。要避免重复，我们先把**右点能覆盖的全部区间**算给右点，再问：左点还能补上哪些区间？

设右点在 $x$，左点在 $y\le x$。一个包含 $y$ 的闭区间，如果右端点 $r\ge x$，它就一定也包含 $x$，已经算过；如果 $r<x$，它就完全没被右点算过。因此，固定 $x$ 后，左点只需在所有 **$r<x$** 的区间里，选一个位置使覆盖的价值最大。回到样例，右点取 $7$ 得到 $11$；在 $7$ 左侧已经结束的区间中，点 $4$ 能补上 $[2,4]$ 和 $[4,6]$ 的 $7+6=13$，合计 $24$。右端点恰好等于 $x$ 仍算在右点这一边。

## 扫过一个右点，需要改哪些数？

---

坐标可达 $10^9$，但只需扫描不同的左端点。对一个已覆盖若干区间的检查点，把它左移到这些区间中**最大**的左端点：新位置不早于其中任何区间的左端点，又不晚于原位置，所以原来覆盖的区间一个都不会丢。权值均为正，多覆盖也无妨。两个点分别移动后重排左右，仍是合法方案；覆盖不到区间的点直接舍去。

设不同左端点从小到大为 $p_1,\ldots,p_k$。每个区间覆盖其中连续的一段，记下标为 $[L,R]$，即 $p_L=l$，$p_R$ 是最后一个不超过 $r$ 的候选点。在差分数组的 $L$ 处加 $w$，在 $R+1$ 处减 $w$；所有区间处理完后取前缀和，便得到每个右点 $p_i$ 单独覆盖的价值 $c_i$。

现在从左往右枚举 $p_i$。给每个候选左点 $p_j$ 记一个数 $v_j$：**在右点左侧已结束的区间中，$p_j$ 能覆盖多少价值**。最初全为 $0$。一个区间第一次满足 $R<i$ 时，它刚成为左点可以补上的区间，应把 $v_L,\ldots,v_R$ 都加上 $w$；此后无论右点怎样右移，它都不用再处理。于是把区间按 $R$ 排序，每次先加入所有尚未加入且 $R<i$ 的区间，再用
$$
c_i+\max_{1\le j\le k}v_j
$$
更新答案。为什么可以取全局最大值？所有更新都落在 $i$ 左边，$j\ge i$ 的位置仍为 $0$；如果最大值为 $0$，只选右点就已达到这个值。

需要的操作只有**一段数同时加、读出全体最大值**，用线段树即可。代码中，整段加的权值留在本节点的 `tag`；更新部分子区间后，父节点的 `mx` 取两个孩子的较大值，再加自己的 `tag`。因为只读取根的最大值，不需要向下推标记。

排序和查找区间边界共 $O(n\log n)$；每个区间至多做一次 $O(\log n)$ 的区间加，总时间 $O(n\log n)$，空间 $O(n)$。价值总和可达 $2\times10^{14}$，差分、树上权值和答案均须用 64 位整数。

### 参考代码

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 200010;
struct node{
	int l,r;
	long long w;
}a[N];
int n,k,p[N];
long long b[N],c[N],mx[N * 4],tag[N * 4];
bool cmp(node x,node y){
	return x.r < y.r;
}
void add(int x,int l,int r,int ql,int qr,long long v){
	if(ql <= l && r <= qr){
		mx[x] += v;
		tag[x] += v;
		return;
	}
	int mid = (l + r) / 2;
	if(ql <= mid) add(x * 2,l,mid,ql,qr,v);
	if(qr > mid) add(x * 2 + 1,mid + 1,r,ql,qr,v);
	mx[x] = max(mx[x * 2],mx[x * 2 + 1]) + tag[x];
}
int main(){
	freopen("watch.in","r",stdin);
	freopen("watch.out","w",stdout);
	ios::sync_with_stdio(false);
	cin.tie(0);
	cin >> n;
	for(int i = 1; i <= n; i++){
		cin >> a[i].l >> a[i].r >> a[i].w;
		p[i] = a[i].l;
	}
	sort(p + 1,p + n + 1);
	k = unique(p + 1,p + n + 1) - p - 1;
	for(int i = 1; i <= k + 1; i++) b[i] = 0;
	for(int i = 1; i <= n; i++){
		a[i].l = lower_bound(p + 1,p + k + 1,a[i].l) - p;
		a[i].r = upper_bound(p + 1,p + k + 1,a[i].r) - p - 1;
		b[a[i].l] += a[i].w;
		b[a[i].r + 1] -= a[i].w;
	}
	c[0] = 0;
	for(int i = 1; i <= k; i++) c[i] = c[i - 1] + b[i];
	sort(a + 1,a + n + 1,cmp);
	for(int i = 1; i <= 4 * k; i++){
		mx[i] = 0;
		tag[i] = 0;
	}
	long long ans = 0;
	int j = 1;
	for(int i = 1; i <= k; i++){
		while(j <= n && a[j].r < i){
			add(1,1,k,a[j].l,a[j].r,a[j].w);
			j++;
		}
		ans = max(ans,c[i] + mx[1]);
	}
	cout << ans << '\n';
	return 0;
}
```

# T3 回文通路（palpath）

---

知识点：双向动态规划、对角线分层

只要有一条通路成为回文，就不必花钱翻转通路以外的格子。先看一条已选好的通路：首尾两格必须相等，第二格与倒数第二格也必须相等，依此类推。若一对格子 $P,Q$ 的数值不同，翻转较便宜的那个就能让它们相等；若数值相同，费用为零。记这笔费用为 $c(P,Q)$。通路只向右、向下走，不会重复经过格子，所以不同对之间不争用同一次翻转，总代价就是各对费用之和。

**怎样边选路边计费？** 从起点派一个人向右或向下走，从终点派另一个人向左或向上走。两人每次各走一步，恰好选定下一对需要相等的格子，当场就能算出这对的费用。例如样例 1，首尾不同，必付 $\min(8,3)=3$。接下来若两人分别走到 $(2,1),(2,2)$，这对再付 $\min(2,9)=2$，而且两格已经相邻，两段接起来就是一条费用为 $5$ 的通路。若前面的人走到 $(1,2)$，后面的人可停在 $(1,3)$ 或 $(2,2)$，这对都要付 $5$，总费用反而是 $8$。

两人各走了 $t$ 步时，设他们的位置为 $P=(x,y)$、$Q=(u,v)$。从起点到 $P$ 的步数是 $(x-1)+(y-1)$，从终点到 $Q$ 的步数是 $(n-u)+(m-v)$。这两个数都等于 $t$，所以只要记住两个行号，列号就确定了：
$$
y=t+2-x,\qquad v=n+m-t-u.
$$
要让两段在中间接起来，须有 $x\le u$ 且 $y\le v$。对于到达同一对 $P,Q$ 的不同走法，两人接下来可选的路完全相同；往中间走也不会再碰到外层已计费的格子。因此只保留已付费用最少的走法。令 $f_t[x][u]$ 表示这个最小值，**包含当前这对**的费用。

初始时只有 $f_0[1][n]=c((1,1),(n,m))$ 可达。考虑两人刚走完第 $t$ 步：到达 $P$ 的最后一步若向右，上一行号仍是 $x$；若向下，上一行号是 $x-1$。同理，到达 $Q$ 的最后一步若向左，上一行号为 $u$；若向上，则为 $u+1$。两人的选择组合起来，正好给出四个前驱：
$$
f_t[x][u]=c(P,Q)+\min\bigl\{
f_{t-1}[x][u],\ f_{t-1}[x-1][u],
f_{t-1}[x][u+1],\ f_{t-1}[x-1][u+1]\bigr\}.
$$
按 $t$ 递增计算，越界、不可达或不满足左上与右下关系的状态一律不参与取最小值。

设整条通路共走 $D=n+m-2$ 步。两人各走 $t$ 步后，中间还差 $D-2t$ 步。取 $t=\lfloor D/2\rfloor$：$D$ 为偶数时两人在同一格，中央格与自己相等，不收费；$D$ 为奇数时两格相邻，连上它们即可，最后这对的费用已计入状态。每条完整通路都能这样从两端走到中间，每个合法终态也能把两段接成一条通路。因此，答案是最后一层所有合法状态的最小值。$1\times1$ 的网格在初始层已经相遇，答案为 $0$。

转置只会互换向下和向右两种走法，不改变费用。令 $s=\min(n,m)$，代码先令较短的一维作行。每层至多 $s^2$ 个状态，每个状态只比较四个前驱，总时间为 $O((n+m)s^2)$。参考程序保留所有层，空间为 $O(nm+(n+m)s^2)$，在最大规模下约占 $338$ MiB。各对费用相加可能超过 $2^{31}-1$，用 `long long` 保存。

### 参考代码

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 355,T = 350;
const long long INF = 4000000000000000000LL;
int n,m,a[N][N];
long long w[N][N],f[T][N][N];
long long cost(int x,int y,int u,int v){
	if(a[x][y] == a[u][v]) return 0;
	return min(w[x][y],w[u][v]);
}
int main(){
	freopen("palpath.in","r",stdin);
	freopen("palpath.out","w",stdout);
	ios::sync_with_stdio(false);
	cin.tie(0);
	cin >> n >> m;
	for(int i = 1; i <= n; i++){
		for(int j = 1; j <= m; j++) cin >> a[i][j];
	}
	for(int i = 1; i <= n; i++){
		for(int j = 1; j <= m; j++) cin >> w[i][j];
	}
	if(n > m){
		for(int i = 1; i <= n; i++){
			for(int j = 1; j <= m && j < i; j++){
				swap(a[i][j],a[j][i]);
				swap(w[i][j],w[j][i]);
			}
		}
		swap(n,m);
	}
	int d = n + m - 2;
	for(int t = 0; t <= d / 2; t++){
		for(int x = 0; x <= n + 1; x++){
			for(int u = 0; u <= n + 1; u++) f[t][x][u] = INF;
		}
	}
	f[0][1][n] = cost(1,1,n,m);
	for(int t = 1; t <= d / 2; t++){
		for(int x = 1; x <= n; x++){
			int y = t + 2 - x;
			if(y < 1 || y > m) continue;
			for(int u = x; u <= n; u++){
				int v = n + m - t - u;
				if(v < y || v > m) continue;
				long long pre = min(f[t - 1][x][u],f[t - 1][x - 1][u]);
				pre = min(pre,f[t - 1][x][u + 1]);
				pre = min(pre,f[t - 1][x - 1][u + 1]);
				if(pre != INF) f[t][x][u] = pre + cost(x,y,u,v);
			}
		}
	}
	long long ans = INF;
	for(int x = 1; x <= n; x++){
		int y = d / 2 + 2 - x;
		if(y < 1 || y > m) continue;
		for(int u = x; u <= n; u++){
			int v = n + m - d / 2 - u;
			if(v < y || v > m) continue;
			ans = min(ans,f[d / 2][x][u]);
		}
	}
	cout << ans << '\n';
	return 0;
}
```

| 2 | $n,m\le30$（5–8） | 20 分 | 对每个子矩形求从左上角到右下角的最小回文费用。重合时为 $0$，相邻时为两端的费用；否则两端各向里走一步，对能连接的组合取内层最小值，再加本对费用。按子矩形的高、宽从小到大计算，答案取整个网格。时间和空间都是 $O(n^2m^2)$。 |
| 复用 1 | $n=1$ 或 $m=1$（9–10） | 10 分 | 通路唯一，枚举不会分支，只需沿这一行或一列从两头逐对计费。用第 1 种程序，时间和空间都是 $O(L)$。 |
| 满分 | 无额外限制（11–20） | 50 分 | 只枚举从整张网格两端同步可达的行号对，按正文的分层 DP 汇总；时间 $O((n+m)s^2)$，参考程序空间 $O(nm+(n+m)s^2)$。 |

第 1 种做法覆盖 1–4、9–10，共 30 分。第 2 种也能做单行或单列：此时子矩形就是一段连续区间，状态数至多 $O(L^2)$，且 $L\le350$；连同两个小规模点组，共覆盖 1–10，计 50 分。

# T4 朋友圈（circle）

---

知识点：离线动态连通性、时间线段树、可回滚并查集

加入一条朋友关系时，只需看它连接的是不是两个不同的朋友圈。如果两圈的代表分别是 $a,b$，合并后就只剩 $\max(a,b)$，代表编号之和减少了 $\min(a,b)$。因此，并查集只要在根上多记一个「圈内最大编号」，就能一边合并一边更新答案。

难处在删除：删掉 $(u,v)$ 后，两人可能还能经第三人相连，也可能真的分属两圈。知道两人原来同圈，不能判断是哪一种。所有操作都在输入中，因此可以换个问题：**对一次查询，怎样只加入那一刻仍然存在的边？**

## 哪些时刻可以共用一次合并？

---

把第 $i$ 次操作**执行后**当作时刻 $i$。一条边在 $l$ 时刻加入，在 $r$ 时刻删除，那么它应参与 $[l,r-1]$ 内的查询。初始边的起点记为 $1$，直到最后仍存在的边活到 $q$。若初始边恰在第一次操作被删，得到的是空区间，直接略过。同一对朋友解除关系后又重新建立关系，就有两段分开的有效时间。

假设要一起回答时间段 $[L,R]$ 里的查询。一条边若在整段都存在，进入这段时合并一次即可；若只在前半段存在，就不能让后半段继承这次合并。于是把 $[1,q]$ 不断对半分。给一条边登记有效区间时，遇到**被完整覆盖的节点就存边并停止往下分**，只在部分覆盖处继续向下。这就是建在操作时间上的线段树。

这些存边节点对应的区间互不相交，拼起来正好是该边的有效期。因而对于时刻 $i$，从根走到叶子 $i$ 的路径恰好遇到每条当前有效的边一次，也不会遇到任何已失效的边。沿路用并查集合并，走到查询叶子时，直接输出各圈最大编号之和。

以样例 1 为例，$(3,4)$ 整场都在，可以放在根；$(1,2)$ 在第 4 次操作被删，只在 $[1,3]$ 有效；$(2,3)$ 的有效期是 $[2,7]$。第 3 次操作查询时，三条边都在，代表是 $4,5$，答案为 $9$。到第 5 次操作查询时，后两条边中只有 $(2,3)$ 还在，代表变成 $1,4,5$，答案为 $10$。要得到第二个答案，遍历必须在离开 $[1,3]$ 时撤去该分支的影响。

## 怎样在离开一段时间后还原？

---

进入节点先记下栈长 $k$，再加入这个节点的边。若两端已经同根，什么也不改。否则设大集合的根为 $x$、小集合的根为 $y$：把 $y$ 挂到 $x$ 下，更新 $x$ 的大小和最大编号，并把总和中的两项替换为合并后的一项。**真正被改写的只有** $y$ 的父亲、$x$ 的大小与最大编号，以及总和。保存两个根和后三项的旧值就够了；$y$ 的父亲原先必是它自己。

递归处理完该节点后，把栈顶的合并倒着撤销，直到栈长重新变成 $k$。这样，处理右孩子时看到的恰好是父节点留下的图，左孩子的边不会串过来。查根时不做路径压缩，否则查找本身也会改写父指针，上述记录就不够了。按大小合并已足够：一个点每加深一层，它所在的集合至少翻倍，所以查根最多走 $O(\log(n+1))$ 步。

代码用有序对 $(\min(u,v),\max(u,v))$ 作键，在 `st` 中记每条现存边的起始时刻。遍历时间树之前，并查集从 $n$ 个单点开始，总和为 $n(n+1)/2$；到 $n=10^5$ 时它超过 32 位有符号整数，须用 `long long`。

登记一段有效期时，每层只有包含左、右边界的区间可能还要往下拆，完整覆盖的区间就在该层停下。因此每段有效期只存入 $O(\log(q+1))$ 个节点，每份存边只尝试合并一次。有效期最多 $m+q$ 段，总时间为 $O(n+(m+q)\log(q+1)\log(n+1))$，空间为 $O(n+q+(m+q)\log(q+1))$。这里已计入有序映射：同时存在的不同边少于 $n^2$，一次插入或删除也是 $O(\log(n+1))$。

### 参考代码

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 100010,Q = 200010;
struct node{
	int x,y,s,m;
	long long ans;
};
int n,m,q,fa[N],sz[N],mx[N],op[Q];
long long ans;
vector<pair<int,int> > v[Q * 4];
vector<node> stk;
map<pair<int,int>,int> st;
int find(int x){
	while(fa[x] != x) x = fa[x];
	return x;
}
void merge(int x,int y){
	x = find(x);
	y = find(y);
	if(x == y) return;
	if(sz[x] < sz[y]) swap(x,y);
	node t;
	t.x = x;
	t.y = y;
	t.s = sz[x];
	t.m = mx[x];
	t.ans = ans;
	stk.push_back(t);
	ans -= mx[x] + mx[y];
	fa[y] = x;
	sz[x] += sz[y];
	mx[x] = max(mx[x],mx[y]);
	ans += mx[x];
}
void add(int x,int l,int r,int ql,int qr,pair<int,int> e){
	if(ql > qr) return;
	if(ql <= l && r <= qr){
		v[x].push_back(e);
		return;
	}
	int mid = (l + r) / 2;
	if(ql <= mid) add(x * 2,l,mid,ql,qr,e);
	if(qr > mid) add(x * 2 + 1,mid + 1,r,ql,qr,e);
}
void dfs(int x,int l,int r){
	int k = stk.size();
	for(int i = 0; i < (int)v[x].size(); i++){
		merge(v[x][i].first,v[x][i].second);
	}
	if(l == r){
		if(op[l] == 3) cout << ans << '\n';
	}else{
		int mid = (l + r) / 2;
		dfs(x * 2,l,mid);
		dfs(x * 2 + 1,mid + 1,r);
	}
	while((int)stk.size() > k){
		node t = stk.back();
		stk.pop_back();
		fa[t.y] = t.y;
		sz[t.x] = t.s;
		mx[t.x] = t.m;
		ans = t.ans;
	}
}
int main(){
	freopen("circle.in","r",stdin);
	freopen("circle.out","w",stdout);
	ios::sync_with_stdio(false);
	cin.tie(0);
	cin >> n >> m;
	st.clear();
	stk.clear();
	for(int i = 1; i <= m; i++){
		int x,y;
		cin >> x >> y;
		if(x > y) swap(x,y);
		st[make_pair(x,y)] = 1;
	}
	cin >> q;
	for(int i = 1; i <= 4 * q; i++) v[i].clear();
	for(int i = 1; i <= q; i++){
		cin >> op[i];
		if(op[i] == 3) continue;
		int x,y;
		cin >> x >> y;
		if(x > y) swap(x,y);
		pair<int,int> e = make_pair(x,y);
		if(op[i] == 1) st[e] = i;
		else{
			add(1,1,q,st[e],i - 1,e);
			st.erase(e);
		}
	}
	map<pair<int,int>,int>::iterator it;
	for(it = st.begin(); it != st.end(); it++){
		add(1,1,q,it->second,q,it->first);
	}
	st.clear();
	ans = 1LL * n * (n + 1) / 2;
	for(int i = 1; i <= n; i++){
		fa[i] = i;
		sz[i] = 1;
		mx[i] = i;
	}
	dfs(1,1,q);
	return 0;
}
```

## 部分分

---

| 序号 | 条件与点组 | 点组分值 | 做法与复杂度 |
|:---:|---|:---:|---|
| 1 | 第 1–4 点：$n\le9,\ q\le24$；第 5–8 点：$n\le200,\ q\le500$ | 各 20 分，共 40 分 | 用邻接表直接增删边。每次查询从各个未访问点开始 BFS，一次搜完一个连通块，把搜到的最大编号计入答案。总时间 $O(n+m+q(n+m+q))$，空间 $O(n+m+q)$。 |
| 2 | 第 9–10 点：没有删边 | 10 分 | 用普通并查集先加入初始边，再按时间顺序合并新增边，按正文的方法维护代表之和。可用路径压缩和按大小合并；总时间 $O(n+(m+q)\alpha(n))$，空间 $O(n)$。 |
| 3 | 第 11–12 点：没有加边 | 10 分 | 从初始边集中去掉全部被删边，用剩余边建出最终的图。倒序处理操作，遇到删除就加回那条边，遇到查询就把总和记在原操作编号上，最后按编号递增输出。用有序集合筛出剩余边，总时间 $O(n+(m+q)(\log(n+1)+\alpha(n)))$，空间 $O(n+m+q)$。 |
| 满分 | 第 13–20 点：无额外限制 | 40 分 | 把有效期分配到时间线段树，用可回滚并查集遍历，覆盖全部 20 点。 |

表中是各点组的分值。根据是否有删边、是否有加边选用相应并查集，两种操作都有时用第 1 种做法，可保证第 1–12 点共 60 分。$\alpha$ 是反阿克曼函数。
