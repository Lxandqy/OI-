# 集结：Lemon 特殊评测

本题答案不唯一，不能用逐字比较判分。提供 `spj.cpp` 与静态链接的 Windows `spj.exe`。

调用格式：

```text
spj.exe 输入文件 选手输出文件 标准答案文件 本点满分 得分文件 报告文件
```

六个参数分别对应 Lemon 原生校验器接口。合法方案写入传入的本点满分，错误方案写入 0，判定说明写入报告文件；正常完成返回 0。调用或评测文件错误返回非零值。

自由编队逐点检查集合内度数；默契小队检查人数、编号唯一性以及内部边数。任意合法方案均接受。选手输出 `-1` 时与经独立验证的标准答案核对是否确实无解。

接口测试覆盖不同合法方案、输出顺序、空白、无解、空输出、越界、重复编号、漏项、非法队伍及多余内容，并以不同本点满分检查实际得分文件。无需在选手包中放入校验器。

将来导入 Lemon 时，把校验器放到该题数据目录并配置为自定义校验器。本次只交付文件和接口测试，不新建第三套 Lemon 比赛，也未声称完成 Lemon 图形界面实测。
