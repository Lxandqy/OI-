## 数字（number）




### 题目描述

Cuber QQ 现在有一个数，他想通过以下操作使得其最终变成一个数字，且要求在这个过程中，操作的次数尽可能地多：
- 每一次可以选择数中任意两个连续的数字 $a$ 和 $b$，将这两个数字所在的位置替换成 $a+b$。例如 $189$ 可以操作前两位变成 $99$；或者操作后两位变成 $117$ 。

### 输入格式


输入包含一行一个数 $n$ ($1\le n< 10^{200000}$) 。

### 输出格式


输出一行一个数，表示答案，即最多的操作次数。



### 样例 1 输入


```
99
```

### 样例 1 输出


```
2
```

## 次数（occurrences）




### 题目描述

Cuber QQ 现在有一个长度为 $n$ 的序列 $a_1,a_2,\cdots,a_n$，他要求你处理他给出的 $m$ 次询问，每一次询问都给出两个整数 $x$ 和 $y$，要求你找到一个 $i$，将他给出的序列分成两部分 $a_1,a_2,\cdots,a_i$ 和 $a_{i+1},a_{i+2},\cdots,a_n$ 使得在 $a_1,a_2,\cdots,a_i$ 中 $x$ 出现的次数 $\bar{x}$ 和在 $a_{i+1},a_{i+2},\cdots,a_n$ 中 $y$ 出现的次数 $\bar{y}$ 的乘积 $\bar{x}\times \bar{y}$ 最大。

### 输入格式


第一行包含两个正整数 $n,m$ ($1\leq n,m\leq 10^5$)。

第二行 $n$ 个正整数 $a_1,a_2,\cdots,a_n$ ($1\leq a_i\leq 10^9$)。

接下来 $m$ 行，每行两个数 $x,y$ ($1\leq x,y\leq 10^9$)，表示一次询问。

### 输出格式


对于每一个询问输出一行，一共 $m$ 行，表示答案。


### 样例 1 输入


```
5 2
1 2 3 2 1
1 2
2 2
```

### 样例 1 输出


```
2
1
```

### 样例解释


两个查询的答案分别为：
- 分割序列为 $1$ 和 $2,3,2,1$，则 $\bar{x}=1,\bar{y}=2$；
- 分割序列为 $1,2$ 和 $3,2,1$，则 $\bar{x}=1,\bar{y}=1$。

## 游戏（game）




### 题目描述

Cuber QQ 在课堂上经常会和同学们玩一个非常经典的擦数游戏，游戏的规则是这样的，一开始黑板上会有 $n$ 个非负整数，每一次，一个同学可以选择其中的任意两个数 $x$ 和 $y$，用黑板擦擦去这两个数后，需要在黑板上重新写下 $\vert x-y\vert $。不断重复这样的操作，黑板上最后一定会剩下一个数，而游戏结束。

而现在，Cuber QQ 对这个游戏进行了修改用以测试同学们的智商水平，Cuber QQ 允许同学们在任意时刻停止擦数游戏（即可以在黑板上剩下任意多数的时候停止游戏），而他希望，在停止游戏的时候，黑板上所有剩下的数中的最小值要尽可能的小，你能求出最后留下的数中可能的最小值是多少吗？

### 输入格式


输入的第一行包含一个正整数 $n$ ($1\le n\le  10^5$)，表示黑板上数的数量。

第二行包含 $n$ 个非负整数 $a_1,a_2,\cdots,a_n$ ($0\le a_i\le 10^9$)，表示黑板上的数。

### 输出格式


输出包含一行一个整数，表示答案。


### 样例 1 输入


```
2
1 5
```

### 样例 1 输出


```
1
```

### 样例解释


显然什么都不做的时候，黑板上的数字 $1$ 更小，因为操作了以后黑板上只会留下一个 $4$。


### 样例 2 输入


```
3
1 4 5
```

### 样例 2 输出


```
0
```

## 子段（subarray）




### 题目描述

Cuber QQ 现在有两个长度为 $n$ 的序列 $a_1,a_2,\cdots,a_n$ 和 $b_1,b_2,\cdots,b_n$ 。对于一个任意的区间 $[L,R]$ ($1\le L\le R\le n$)，Cuber QQ 想要找到这个区间的一个长度至少为 $k$ 的子区间 $[l,r]$ ($L\le l\le r\le R$ 且 $r-l+1\ge k$) ，使得 $\sum_{i=l}^r a_i/\sum_{i=l}^r b_i$ 最大。

现在 Cuber QQ 会给出 $q$ 个区间 $[L_1,R_1],[L_2,R_2],\cdots, [L_q,R_q]$，你需要回答每一次询问的问题。其中对于任意一个询问的区间 $[L_i,R_i]$，假设上一个询问的答案的**分子**为 $ans$ （即询问 $[L_{i-1},R_{i-1}]$ 的答案，如果 $i=1$，则认为 $ans=0$），则实际询问的区间是
- $L=(L_i\oplus (ans\times type))\bmod n +1$,
- $R=(R_i\oplus (ans\times type))\bmod n +1$。
- 如果 $L>R$，则交换 $L,R$。
- 其中 $\oplus$ 表示二进制下的异或运算。
- 其中 $type\in \{0,1\}$，显然 $type=0$ 的时候表示的是允许离线的算法，而 $type=1$的时候要求强制在线。

### 输入格式


第一行包含四个整数 $n,k,q,type$ ($1\le n,q\le 10^6$,$1\le k\le 20$,$type\in \{0,1\}$)，分别表示序列的长度，要求找到区间的最小长度，询问次数和是否要求强制在线。

第二行包含 $n$ 个整数 $a_1,a_2,\cdots,a_n$ ($1\le a_i\le 10^7$)。

第三行包含 $n$ 个整数 $b_1,b_2,\cdots,b_n$ ($1\le b_i\le 10^7$)。

接下来的 $q$ 行，每行包含两个整数 $L_i,R_i$，表示询问 ($1\le L_i,R_i\le n$)。

### 输出格式


对于每一个询问输出一行，一个最简分数 `a/b` 表示答案，即要求 $gcd(a,b)=1$。如果不存在满足要求的答案，则输出 `0/1` 。


### 样例 1 输入


```
5 2 3 1
2 4 1 3 7
6 1 5 2 4
1 2
1 4
4 4
```

### 样例 1 输出


```
5/6
5/3
0/1
```

### 样例解释


实际的查询区间和答案为：
- $[2,3]$，答案是 $\frac{4+1}{1+5}=5/6$;
- $[2,5]$，答案是 $\frac{3+7}{2+4}=5/3$;
- $[1,1]$，不存在长度至少为 $2$ 的区间。
