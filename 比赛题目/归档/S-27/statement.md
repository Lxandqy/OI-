## 取模（mod）




### 题目描述

初始时给定一个正整数 $x$ 和一个长度为 $n$ 的正整数序列 $a$。

你可以执行以下操作任意次（可以不执行）：

选择一个参数 $i$，满足 $1 \leq i \leq n$，把 $x$ 修改为 $x \bmod a_i$。

请问可以得到的最小的 $x$ 为多少。

其中 $x \bmod a_i$ 表示 $x$ 对 $a_i$ 取模后的结果。

### 输入格式


第一行包含 $2$ 个正整数 $n,x$。

第二行给定长度为 $n$ 的序列 $a$。

### 输出格式


输出一行，输出 $1$ 个整数，表示最终答案。



### 样例 1 输入


```
3 1000
17 89 99
```

### 样例 1 输出


```
4
```

### 样例 1 解释


可以得到的数有 $1000,14,21,4,10$，其中 $4=(1000 \bmod 89) \bmod 17$。


### 样例 2 输入


```
8 1000000000000000000
89899982 998244353 12313242 12321321321123 2133 4141414 89898989 79797979
```

### 样例 2 输出


```
9
```

## 排列（permutation）




### 题目描述

对于一个长度为 $n$ 的全排列，我们通过以下方式生成一个长度为 $n-1$ 的数组 $a$，称为它的特征数组：

$\forall i \in [1, n), a_i=\max(p_i,p_{i+1})$。


现在给出一个长度为 $n$ 的全排列 $p$，请问有多少个长度为 $n$ 的全排列 $q$，$p$ 和 $q$ 的特征数组完全一样，答案对$998244353$ 取模。

长度为 $n$ 的全排列为一个长度为 $n$ 的两两不同的数组，且每个元素大小均在 $[1:n]$ 内。

### 输入格式


第一行一个正整数 $T$，表示数据组数。

之后对于每组数据，第一行给出一个正整数 $n$ 。

第二行给出一个长度为 $n$ 的全排列 $p$ 。

### 输出格式


输出一个整数，表示答案。


### 样例 1 输入


```
3
3
1 3 2
8
4 1 8 5 6 7 3 2
12
1 3 2 6 7 5 4 10 9 8 11 12
```

### 样例 1 输出


```
2
16
8
```

### 样例 1 解释


对于第一组数据，满足要求的解有 $[1,3,2]$ 和 $[2,3,1]$ 。

## 机器人（bot）




### 题目描述

有一个 $n \times m$ 的网格图，每个格子上有墙壁或者空地，机器人可以在空地上行动。

机器人初始时在网格图的一个空地位置，用 `R` 表示，他要走到空地位置 `E` 上。

系统给出了一串指令，由 `U`，`D`，`L`，`R` 组成，机器人会按照这个指令移动，如果下一步有墙或者出了边界，则跳过该操作，如果机器人到达终点则会立即停止移动。

每次操作，你可以在指令中任意位置插入一个新的字母，或者删除指令中的任意位置的一个字母，问你最少进行多少次操作，使得机器人能到达 `E`。

### 输入格式


输入一行，正整数 $n,m$。

之后输入 $n$ 行给出网格图的具体形态。

之后输入一行，给出一个字符串 $S$ ，表示指令。

### 输出格式

```

```

### 样例 2 输出


## 道路（road）




### 题目描述

M 国有 $n$ 个城市，任意两个城市之间都有道路直接连接，经过每条道路都会收取一定的过路费，其中一辆货车从 $i$ 号城市走到 $j$ 号城市会收取 $a_{i,j}$ 的过路费，**注意 $a_{i,j}$ 和 $a_{j,i}$ 可能不等**。

现在 M 国发生了若干次道路费用政策调整，第 $i$ 次调整发生在第 $i$ 天，使得第 $x_i$ 个城市和第 $y_i$ 个城市之间的道路不再收取费用，即将 $a_{x_i,y_i},a_{y_i,x_i}$ 调整为 $0$，在该天结束后，$a_{x_i,y_i},a_{y_i,x_i}$ 的费用会重新调整为原来的值。

小 C 开了一家物流公司，每天都有 $c_{i,j}$ 辆货车从城市 $i$ 走到城市 $j$，对于每辆货车，每天都会选择过路费之和最小的一条路径。小 C 想知道，在第 $i$ 天，小 C 的物流公司需要支付的总过路费最小是多少。

### 输入格式


第一行包含 $2$ 个正整数，表示 $n,q$。

之后 $n$ 行，第 $i$ 行给出 $n$ 个整数，其中第 $j$ 个表示 $a_{i,j}$。特别的，保证 $a_{i,i}=0$。

之后 $n$ 行，第 $i$ 行给出 $n$ 个整数，其中第 $j$ 个表示 $c_{i,j}$。特别的，保证 $c_{i,i}=0$。

之后 $q$ 行，第 $i$ 行给出 $2$ 个正整数，表示 $x_i,y_i$，保证 $x_i≠y_i$。

### 输出格式


对于每次询问，输出一个整数，表示答案。


### 样例 1 输入


```
3 3
0 4 2
3 0 6
5 1 0
0 2 1
1 0 2
1 2 0
1 2
2 3
1 3
```

### 样例 1 输出


```
9
12
13
```

### 样例 1 解释


对于第一次询问，$(1,2),(2,1)$ 最小费用为 $0$，$(1,3),(2,3)$ 最小费用为 $2$，$(3,2),(3,1)$ 最小费用为 $1$，所以答案为 $9$。

对于第二次询问，$(2,3),(3,2)$ 最小费用为 $0$，$(1,2),(1,3)$ 最小费用为 $2$，$(2,1),(3,1)$ 最小费用为 $3$，所以答案为 $12$。

对于第三次询问，$(1,3),(3,1)$ 最小费用为 $0$，$(2,1),(2,3)$ 最小费用为 $3$，$(1,2),(3,2)$ 最小费用为 $1$，所以答案为 $13$。
