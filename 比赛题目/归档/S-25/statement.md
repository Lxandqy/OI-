## 精灵（elf）




### 题目描述

在遥远的艾瑟利亚大陆上，生活着一群拥有魔法与智慧的生物——精灵。这些精灵们根据各自的天赋、属性以及能量，可以量化出一个能力值，其中第 $i$ 只精灵的能力值为 $w_i$。

在艾瑟利亚大陆的边陲，一片被古老诅咒笼罩的幽暗之地，恶魔势力悄然崛起，威胁着整个大陆的和平与安宁。这些恶魔，由黑暗与邪恶的力量孕育而生，它们渴望吞噬光明，将艾瑟利亚拖入无尽的黑暗之中。

为了阻止恶魔势力的崛起，精灵女王希望把 $n$ 只精灵进行分组，从而在战略上增加抵御恶魔的可能性。同时，为了提高小组的灵活性，每个小组**至多**只能有 $2$ 只精灵。一个小组的能力值定义为该小组内所有精灵的能力值之和，为了平衡每个小组的实力，精灵女王希望能力值最大的小组的能力值减去能力值最小的小组的能力值的权值尽量小，请你告诉她这个权值至少是多少。

### 输入格式


输入共一行，包含一个正整数 $n$。

第二行包含 $n$ 个整数，第 $i$ 个整数表示 $w_i$，表示第 $i$ 只精灵的能力值。

### 输出格式


输出一行，包含一个整数，表示能力值最大的小组的能力值减去能力值最小的小组的能力值的最小值。



### 样例 1 输入


```
4
1 3 7 6
```

### 样例 1 输出


```
1
```

### 样例 1 解释


最优解为 $(1,7)$ 和 $(3,6)$，差值为 $1$。


### 样例 2 输入


```
7
2 8 9 15 17 18 16
```

### 样例 2 输出


```
2
```

### 样例 2 解释


最优解为 $(2,15),(8,9),(17),(18),(16)$。

## 排列（permutation）




### 题目描述

给定一个长度为 $n$ 的全排列 $p$。

你可以执行以下操作若干次：

选择一个区间 $l,r$，满足 $1 \leq l \leq r \leq n$，花费 $r-l$ 的代价将排列 $p$ 中下标为 $l,l+1,\ldots r$ 的所有元素从小到大进行排序，其他元素不变。

例如对于排列 $p=[1,3,6,2,4,5]$，选择区间 $l=2,r=4$ 后，排列会变为 $[1,2,3,6,4,5]$。

设 $f_{l,r}$ 表示在只考虑排列 $p$ 的区间 $[l,r]$ 的前提下，让子序列 $[p_l,p_{l+1},...,p_r]$ 有序的最小代价和。

试输出
$$
\sum_{i=1}^n \sum_{j=i}^n f_{i,j}
$$

### 输入格式


输入第一行，包含 $1$ 个正整数 $n$。

输入第二行，包含 $n$ 个正整数 $p_1,p_2,...p_n$。

### 输出格式


输出一行，表示答案。


### 样例 1 输入


```
3
1 3 2
```

### 样例 1 输出


```
2
```


### 样例 2 输入


```
5
1 3 2 4 5
```

### 样例 2 输出


```
6
```


### 样例 3 输入


```
8
1 3 2 4 8 6 7 5
```

### 样例 3 输出


```
45
```

## 魔法（magic）




### 题目描述

在一个遥远的魔法王国里，图书馆里藏有一本神秘的魔法书，这本书收录了 $n$ 个魔法咒语。

小 Z 是魔法王国中的一员，他现在需要创造新的咒语，这些新咒语必须遵循以下两个规则之一：

1. 新咒语必须是魔法书中已有的咒语。
2. 新咒语可以由两部分组成，其中第一部分是魔法书中的一个咒语或者该咒语的非空开头部分（非空前缀），第二部分是魔法书中的一个咒语或者该咒语的非空结尾部分（非空后缀）。这两部分可以来自同一个咒语。

小 Z 想知道，按照这些规则，他们能创造出多少种不同的**新**咒语。

### 输入格式


第一行一个整数 $n$ 表示魔法咒语个数。

接下来 $n$ 行，每行一个魔法咒语。

### 输出格式


输出一个整数，表示答案。


### 样例 1 输入


```
3
abc
def
abef
```

### 样例 1 输出


```
60
```

## 宴会（feast）




### 题目描述

小 X 是一位远近闻名的魔法厨师。最近，某位大魔导师送给了他一件神秘的魔法厨具。小 X 决定用这件魔法厨具制作出全大陆最令人惊叹的料理。

这件魔法厨具可以制作出 $n$ 种食材组合，编号为 $1$ 到 $n$ ，第 $i$ 种食材组合的美味度为 $A_i$（可能为负，也可能为正——毕竟有的料理可能是“黑暗料理”）。

一个传奇料理由若干个连续编号的食材组合制成，包含的食材组合个数不少于 $L$ 且不多于 $R$ 。

我们定义传奇料理的美味度为其包含的所有食材组合美味度之和。若两个传奇料理使用的食材编号集合相同，则认为它们是同一个传奇料理。

小 X 打算制作一桌由 $k$ 个不同的传奇料理组成的宴席。我们定义整桌宴席的总美味度为这 $k$ 个传奇料理美味度之和。小 X 想知道——他能做出总美味度最大的宴席是多少？

### 输入格式


第一行输入四个正整数 $n, k, L, R$ ，分别表示食材组合的数量、宴席中传奇料理的数量，以及每个传奇料理允许使用的最少与最多食材数。

接下来 $n$ 行，每行一个整数 $A_i$，表示第 $i$ 个食材组合的美味度。

### 输出格式


输出一个整数，表示宴席的最大总美味度。


### 样例 1 输入


```
4 3 2 3
3
2
-6
8
```

### 样例 1 输出


```
11
```

### 样例 1 解释


共有 $5$ 种不同的传奇料理：

1. 食材 $1 \sim 2$，美味度为 $3 + 2 = 5$；
2. 食材 $2 \sim 3$，美味度为 $2 + (-6) = -4$；
3. 食材 $3 \sim 4$，美味度为 $(-6) + 8 = 2$；
4. 食材 $1 \sim 3$，美味度为 $3 + 2 + (-6) = -1$；
5. 食材 $2 \sim 4$，美味度为 $2 + (-6) + 8 = 4$。

最优方案是选取料理 $1, 3, 5$，总美味度为 $5 + 2 + 4 = 11$。


### 样例 2 输入


```
10 21 3 5
609
613
288
-114
-83
-36
-136
-60
722
-861
```

### 样例 2 输出


```
5128
```
