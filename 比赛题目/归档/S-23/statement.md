## 合并（makise）




### 题目描述

有一个正整数序列 $a$，两人进行游戏，规则如下：

- 当序列中只有一个元素时，游戏结束。
- 否则，两人交替操作，每次需要选出 $a$ 中的两个元素 $a_i,a_j(i\ne j)$，将它们删除并插入一个值为 $\lfloor\frac{a_i+a_j}{2}\rfloor\cdot 2$ 的元素。

先手希望使得最终 $a$ 中留下的数最大化，后手希望最小化，两人都按最优策略进行游戏。求对于给定的长为 $n$ 的序列 $a$ 的**每个非空前缀**，对该前缀进行游戏的结果，即最后留下的数。

### 输入格式


第一行一个正整数 $n$，表示序列长度。

接下来 $n$ 个正整数，描述序列 $a$。

### 输出格式


输出一行表示所求的答案。



### 样例 1 输入


```
6
6 3 7 2 5 4
```

### 样例 1 输出


```
6 8 16 18 22 26
```


### 样例 2 输入


```
5
7 13 11 19 1
```

### 样例 2 输出


```
7 20 30 48 50
```


### 样例 3 输入


```
3
3 10 11
```

### 样例 3 输出


```
3 12 24
```

## 排序（sort）




### 题目描述

蚁后 Q 的蚁群正筹划着一场盛大的阅兵仪式，蚁后 Q 把蚁群中的兵蚁们分成若干纵队，设某个兵蚁纵队现在有 $n$ 只兵蚁，兵蚁们排成一个序列 $a$，第 $i$ 只兵蚁的战斗力为 $a_i$。蚁后 Q 的兵蚁们都接受过蚁后 Q 的训练，这使得兵蚁们能听懂蚁后 Q 的指挥：

- 选择一个区间 $[l, r]$，区间内的兵蚁们将按照战斗力从低到高排序，即设排序后的兵蚁序列为 $a'$，那么将有 $a'_l\leq a'_{l+1}\leq \dots \leq a'_r$

蚁后 Q 希望把此纵队的兵蚁们按照战斗力排成序列 $b$，因为这样能最好地展现蚁后 Q 蚁群的实力。

### 输入格式


第一行一个正整数 $T$，表示蚁后 Q 将兵蚁们分成了 $T$ 个兵蚁纵队

接下来对于每个纵队：

- 第一行一个正整数 $n$，表示纵队中兵蚁的数量
- 第二行 $n$ 个正整数 $a[1\dots n]$，表示该纵队中兵蚁当前的排序
- 第三行 $n$ 个正整数 $b[1\dots n]$，表示蚁后 Q 期望该纵队兵蚁最终的排序

### 输出格式


对于每个兵蚁纵队，首先输出一行 `0/-1`

- 若蚁后 Q 无法指挥兵蚁们按战斗力最终排序为 $b$，则输出 `-1`
- 若蚁后 Q 可以指挥兵蚁们按战斗力最终排序为 $b$，则输出 `0`

若第一行输出为 `0`，第二行输出一个整数 $m$ 表示蚁后 Q 需要指挥的次数，接下来 $m$ 行每行两个正整数 $l, r$，表示蚁后 Q 指挥的区间为 $[l, r]$，注意一个合法的指挥方案需要满足以下条件：

- $m\leq n^2$
- 每次指挥都要保证 $1\leq l\leq r\leq n$
- 指挥结束后，$a, b$ 相等

若存在多个合法的指挥方案，输出任意一个即可。

## 行走（walk）




### 题目描述

Alice 给出了一张 $n$ 个点 $m$ 条边的强连通有向图，即每对点两两可达，每条边上有一个标记 `(` 或 `)`。

Bob 希望从一个节点出发，遍历所有节点**至少一次**，最终回到该节点，并且最终经过的所有边的标记按顺序依次连接，得到的字符串恰好为一个合法的括号匹配。

Alice 想知道是否存在这样一条路径。

**图中可能有重边和自环。**

### 输入格式


输入第一行，包含 $2$ 个正整数 $n,m$。

之后 $m$ 行，每行给出两个正整数和一个字符 $u_i,v_i,c_i$，其中 $c_i$ 表示边上的标记。

### 输出格式


输出一行，存在输出 `Yes`，否则输出 `No`。


### 样例 1 输入


```

2 3 )
3 4 (
4 1 )
2 4 )

5 1 )
```

### 样例 1 输出


```
Yes
```

### 样例 1 解释


一条合法路径为 $1,2,3,4,1,2,4,5,1$，字符串为 ``()()()()``。

## 猜拳（jkp）




### 题目描述

JKP(Jan-Ken Punch) 挑战赛是 JKP 村一年一度的盛会，JKP 村人才辈出，因此所谓的 JKP 挑战赛其实是村民们基于 Jan-Ken Punch 规则而考验快速计算能力的大赛。此次 JKP 大赛中请来了 $n$ 位志愿者，每位志愿者手持石头（用字符 `A` 表示）、剪刀（用字符 `B`）表示或布（用字符 `C` 表示）中的一个，$n$ 位志愿者根据手上持有的石头、剪刀或布可以用序列 $\{a_n\}$ 表示，$a_i$ 即为第 $i$ 位志愿者手持的物品（一个物品就是【一个石头】、【一个剪刀】或者【一个布】）。而挑战者需要完成多次形如 $[l, r]$ 的询问：

1. 挑战者手持给定物品（石头剪刀或布之一）从第 $l$ 位志愿者处出发
2. 挑战者与当前面对的志愿者进行一次 JKP 对战（其实就是石头剪刀布对战），若挑战者胜利，那么手持物品不变，否则挑战者将手持物品更改为当前面对的志愿者手持的物品
3. 挑战者走向下一位志愿者
4. 若挑战者移动到位置 $r+1$，则询问立即结束，挑战者向主办方汇报当前手持物品，否则回到步骤 2.

小 J 也决定参与此次 JKP 挑战赛，因此小 J 将面对如下格式的 $m$ 次询问：

- 修改询问：给出 $l, r, x, y$，表示 $[l, r]$ 中的所有志愿者若手持物品 `x`，则替换成物品 `y`；若手持物品 `y`，则替换成物品 `x`
- 挑战询问：给出 $l, r, x$，表示小 J 需要手持物品 `x` 经过 $[l, r]$，并向主办方汇报最终手持物品

请注意，挑战询问结束后，每个志愿者手上的物品会恢复原样，而修改询问会改变志愿者手上的物品。

### 输入格式


第一行两个数 $n, m$，含义如题所示

第二行一个长为 $n$，仅由 `A, B, C` 组成的字符串，含义如题所示

接下来 $m$ 行，每行第一个数为 $o p \in\{0,1\}$：

- 若 $o p=0$ 则表示一个修改询问 $l, r, x, y$
- 若 $o p=1$ 则表示一个挑战询问 $l, r, x$

其中 $1 \leq l \leq r \leq n$ 且 $x, y\in\{A, B, C\}$，所有数和字符用空格隔开

### 输出格式


对于每个挑战询问，输出一行表示小 J 最终手持物品对应的字符


### 样例 1 输入


```
6 8
AABAAC
0 2 4 A C
1 5 6 A
1 5 6 C
0 1 2 C A
1 2 5 C
1 1 3 A
0 2 4 B C
1 2 3 C
```

### 样例 1 输出


```
C
C
A
B
C
```
