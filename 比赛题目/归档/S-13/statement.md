## 反转（reverse）




### 题目描述

小A与小B是好朋友，小A有一个序列 $a_1, a_2, ..., a_n$ ，他想用这个序列来构造一个新序列送给小B。

新序列一开始为空，然后对于 $i = 1, 2, ..., n$ 依次进行如下操作：

- 将 $a_i$ 插入序列末尾
- 将整个序列反转

你能帮小B求出最终的序列吗？

### 输入格式


输入的第一行包含一个整数 $n$。

第二行 $n$ 个整数，表示 $a_1, a_2, ...a_n$ 。

### 输出格式


输出一行，为最终的序列。



### 样例 1 输入


```
4
1 2 3 4
```

### 样例 1 输出


```
4 2 1 3
```

## 物流（logistics）




### 题目描述

物流网络的搭建中，成本控制是重要的一环。

- 在平面上有 $n$ 个物流仓库，它们分别位于二维坐标 $(x_i, y_i) (1 ≤ i ≤ n)$ 处。

- 任意两个仓库之间都可以建设物流道路。物流道路是双向的，且对于仓库 $i$ 和仓库 $j$ ( $1 ≤ i, j ≤ n$ 且 $i \neq j$ )，在它们之间建设物流道路的成本为 $\vert x_i - x_j\vert ^3 + \vert y_i - y_j\vert ^3$。

- 物流网络搭建的目标是，使用最小的总成本，建设一些物流道路，使得任意两个仓库都可以直接或间接通过物流道路互相到达。

在解决上述问题的过程中，你发现建设成本是在不断变化的。具体来说：

- 依次发生了 $q$ 个事件，在第 $i$ 个事件中，你发现仓库 $u_i$ 和仓库 $v_i$ 之间可以建设一条双向的专用物流道路，其成本为 $c_i$。
- 专用物流道路与其他物流道路在建设后的作用相同，均为双向连接两个仓库；这两种道路仅有的区别是成本不同。
- 每一对仓库之间的物流道路，以及每一条专用物流道路，其建设与否，均可独立选择。选择不建设时，该物流道路不产生成本。

现在，请在第一个事件之前（即没有专用物流道路时），以及在每个事件后，计算物流网络搭建的最小总成本。

### 输入格式


输入的第一行包含两个整数 $n$ 和 $q$，表示物流仓库的个数，以及事件的个数。

接下来 $n$ 行，第 $i $ 行包含两个整数 $x_i, y_i$，表示第 $i$ 个物流仓库的二维坐标。

接下来 $q$ 行，第 $i $ 行包含三个整数 $u_i, v_i, c_i$，表示第 $i $ 个事件中，新增专用物流道路的属性。

输入中每行相邻的整数之间由一个空格隔开。

### 输出格式


输出 $q + 1$ 行，第 $i$ 行包含一个整数，表示第 $ (i - 1) $ 个事件后物流网络搭建的最小总成本。


### 样例 1 输入


```
4 2
0 0
1 1
-2 1
-2 2
1 2 5
1 4 3
```

### 样例 1 输出


```
12
12
6
```

## 序列（sequence）




### 题目描述

$a,b$ 为两个长度为 $n$ 的序列，定义它们的距离为 $\sum_{i=1}^n(a_i-b_i)^2$。

现在给你两个序列 $a$ 和 $b$，你可以任意交换 $a$ 中的两个元素。

请你求出经过若干次交换之后，两个序列的最小距离，对 $998244353$ 取模。并求出最少的交换步数。

保证 $a,b$ 序列中没有相同的元素，即 $ i\neq j$，则 $a_i\neq a_j,\  b_i\neq b_j$ 。

### 输入格式


第一行两个数字 $n, \ T$ ，分别表示序列长度和任务类型 。

第二行 $n$ 个整数，表示 $a_1, a_2, ...a_n$ 。

第三行 $n$ 个整数，表示 $b_1, b_2, ...b_n$ 。

### 输出格式


第一个数，输出两个序列的最小距离对 $998244353$ 取模的结果。

如果 $T=0$ ，则只输出第一个数，否则，第二个数输出最小交换次数。两个数用空格分开。


### 样例 1 输入


```
5 1
4 5 3 1 2
2 5 1 4 3
```

### 样例 1 输出


```
0 3
```

## 魔法（magic）




### 题目描述

小M是一名魔法师，有无限多个魔法石。

他为了施展魔法，需要将魔法石放入魔法阵中。

魔法阵是一个大小任意的方阵，设其第 $i$ 行 $j$ 列中有 $a_{i,j}$ 个魔法石，需要满足如下性质：

1. $a_{i,j}\ge m$
2. 设魔法阵大小为 $k$ ，任意从魔法阵选出 $k$ 个格子，满足任意两个格子不在同一行且不在同一列(有 $k!$ 种选法)，那么选出的 $k$ 个格子的石子数之和是相同的(也就是与格子的选法无关)
3. 魔法阵中对角线石子数之和不超过 $n$

其中 $n,m$ 为给定常数，你需要帮助小M计算有多少种可能的魔法阵，结果对$998244353$取模。

### 输入格式


第一行一个数 $T$，为数据组数。

接下来 $T$ 行，每行两个数 $n,m$。

### 输出格式


每组数据输出一行一个数表示答案。


### 样例 1 输入


```

1 1
2 1
3 1
4 1
5 1
```

### 样例 1 输出


```

3
9
26
73
```
