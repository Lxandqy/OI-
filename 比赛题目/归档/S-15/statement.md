## 纸牌（poker）




### 题目描述

小 C 手上有 $n$ 张扑克牌，按照 $1,2,\cdots,n$ 的顺序排列。一开始，有些牌是正面朝上的，有些牌则是背面朝上的，而小 C 希望所有的牌都能调整为正面朝上。

这些牌有一种奇怪的特性，当小 C 翻转第 $i$ 张牌时，牌 $i+1,i+2,\cdots,r_i$ 也会在同一时刻翻转（当 $r_i=i$ 时，没有额外的牌被翻转），而其他的牌保持不变。此外，小 C 翻转第 $i$ 张牌需要 $t_i$ 的时间。

小 C 想知道最少多少时间后，所有的牌都能变为正面朝上。

### 输入格式


第一行包含一个整数 $n$，表示扑克牌的张数。

第二行包含一个长度为 $n$ 的字符串 $s_1s_2\cdots s_n$，当 $s_i$ 为 `0` 时表示正面朝上，而 $s_i$ 为 `1` 时表示背面朝上。

第三行包含一个长度为 $n$ 的数组 $r_1,r_2,\cdots,r_n$，其中 $r_i$ 表示翻转牌 $i$ 时，影响到的最右侧牌。

第四行包含一个长度为 $n$ 的数组 $t_1,t_2,\cdots,t_n$，其中 $t_i$ 表示翻转牌 $i$ 所需的时间。

### 输出格式


输出一个整数，表示小 C 所需的最小时间。



### 样例 1 输入


```
9
110101011
4 3 8 5 8 6 9 8 9
1 2 3 4 5 6 7 8 9
```

### 样例 1 输出


```
23
```

## 代码（code）




### 题目描述

小 C 需要编写一段代码，这段代码由 $ n $ 行组成。为了方便起见，我们将每一行代码表示为一个长度为 $ m $ 的二进制串。要求按顺序编写每一行的代码。

小 C 有两种编写代码的方式：

- **直接编写**：小 C 直接编写一行代码，这将花费 $ c $ 的代价。
- **复制和修改**：小 C 可以选择从已经写好的某一行代码中复制一行，并对其进行修改。复制操作本身花费 $ 1 $ 的代价。对于每个不同的二进制位，修改一个位花费 $ 1 $ 的代价。

请帮助小 C 计算出编写这段代码的最少代价。

### 输入格式


第一行包含三个整数 $ n $、$ m $、$ c $，分别表示代码的行数、每行代码的长度以及直接编写一行代码的代价。

接下来的 $ n $ 行每行包含一个长度为 $ m $ 的二进制串，表示需要编写的每一行代码。

### 输出格式


输出一个整数，表示小 C 编写这段代码所需的最少代价。


### 样例 1 输入


```
5 3 4
101
010
111
001
110
```

### 样例 1 输出


```
14
```

## 回文（palindrome）




### 题目描述

小 C 发现了一种具有特殊性质的正整数，这些数的数码是中心对称的（也即是翻转之后是它本身），小 C 将这些数称作“对称数”。例如 $6,121,4994,1923291$ 都是对称数，而 $123,666766$ 则不是。

某一天，小 C 写下了两个他非常喜欢的对称数 $x$ 和 $y$，将这两个数求和，就得到了他的幸运数字。

过了很久很久，小 C 遗忘了最初的两个对称数 $x,y$，只记得幸运数字 $n$ 了。

他很好奇，最初的两个对称数 $(x,y)$ 有多少种可能。当 $x\not=y$ 时，$(x,y)$ 与 $(y,x)$ 是两种不同的方案。

### 输入格式


输入仅包含一个整数 $ n $。

### 输出格式


输出一个整数，表示满足条件的 $ (x, y) $ 对数。


### 样例 1 输入


```
1231
```

### 样例 1 输出


```
56
```

## 比赛（match）




### 题目描述

Floating Island 正在举办一年一度的魔法比赛，共计有 $n$ 个人参加，有三种不同的场地，每一名选手在不同的场地上有不同的排名。

作为比赛的裁判，小 I 每次可以任意选择两名没有被淘汰的选手进行比赛，并且指定一种比赛场地，然后在这种场地上较弱的选手会被淘汰。

由于魔法的世界在不断地变化，现在有若干的询问和修改的事件，每一次修改会交换两名选手在某一种场地上的排名。

每次询问，小 I 想知道 $x$ 号选手有没有可能赢得**最终的胜利**。请你帮助她回答这些问题。

### 输入格式


第一行包含两个整数 $n$ 和 $q$ ，表示选手数量和询问以及修改的事件数量。

接下来三行，每行一个 $1$ 到 $n$ 的全排列，第 $i$ 位表示排名为 $i$ 的选手编号。从左往右，战斗力逐渐变弱。

接下来 $q$ 行有以下两种类型：

- $1$ $x$ ：表示询问 $x$ 能否赢得最终的胜利。
- $2$ $p$ $a$ $b$：表示交换了第 $p$ 种场地中选手 $a$ 和 $b$ 的排名。

### 输出格式


对于每个询问，输出一行 `Yes` 或 `No` 。


### 样例 1 输入


```
4 4
1 2 3 4
2 1 3 4
2 4 3 1
1 1
1 4
2 3 1 4
1 4
```

### 样例 1 输出


```
Yes
Yes
No
```


### 样例 2 输入


```
6 7
4 6 1 5 3 2
5 1 4 2 6 3
4 6 1 5 2 3
1 2
2 2 4 5
1 1
2 2 4 5
2 2 5 6
1 2
1 1
```

### 样例 2 输出


```
Yes
No
No
Yes
```
